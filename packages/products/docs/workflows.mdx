# Workflows

- `items`: create, get, list, update, disable, enable, archive, delete, markTransacted, tax add/list/remove, supplier-code add/list/remove, customer-code add/list/remove
- `groups`: create, get, list, tree, update, delete, disable, enable
- `brands`: create, get, list, update, delete
- `manufacturers`: create, get, list, update, delete, part add/list/remove
- `attributes`: create, get, list, update, delete, value add/list/update/remove
- `variants`: create, createCombinations, get, list, disable, enable, syncFromTemplate, template-attribute add/list/remove
- `barcodes`: add, list, remove
- `alternatives`: add, list, remove
- `itemUoms`: add, list, update, remove, recalculate
- `reorderRules`: create, get, list, update, disable, enable, delete
- `settings`: get, update
- `lookups`: getByCode, getByBarcode, listByGroup, resolveDefaults, getReorderRules
- `priceLists`: create, get, list, update, disable, enable, delete, seed (idempotent `Standard Selling`/`Standard Buying` seeding)
- `itemPrices`: create, get, list, update, expire, cancel, delete (draft + unused only), assignToParties, hasReferences (item-delete coordination guard)
- `priceFetch`: getRate (deterministic specificity → validity → min-qty → lead-time fetch with UOM conversion and auto-insert), getRatesForList, getActiveForItem, getExpiring
- `pricelistSettings`: get, update

State transitions (enable/disable/archive/cancel/expire/delete) are guarded by `services/lifecycle.ts`: same-state and terminal-state requests fail loudly instead of emitting duplicate events. Enable verbs publish `products.{item,item_group,price_list,reorder_rule,variant}_enabled`; `item-price.cancel` publishes `products.item_price_cancelled`.
