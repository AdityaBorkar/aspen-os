---
title: Masters
description: Polymorphic tenant master data module — contacts, addresses, bank accounts, integration connections, and notes.
icon: IconDatabase
---

The Masters module owns five polymorphic tenant master-data entities: `contact`, `address`, `bankAccount`, `connection`, and `note`. Every entity is scoped to an owner via `(entityType, entityId)` where the owner type is one of `organization`, `branch`, `connection`, or `contact`.
