---
title: Masters
description: Polymorphic master data and reference data module.
icon: IconDatabase
---

The Masters module owns polymorphic tenant master data — contacts, addresses, connections, payment methods — plus taxonomy (`master_label`, `master_entity_label`, `org_branch`) and reference tables (`master_entity`, `master_unit_of_measure`, `master_setting`).
