Workflow groups via `p.masters` — `addresses`, `contacts`, `entities`, `orgBranches`, `paymentMethods`, `settings`, `unitsOfMeasure`, `labels`, and `connections` (access key `p.masters`).

Scoped groups (`addresses`, `contacts`, `connections`, `paymentMethods`) require `entityType` + `entityId` on create/list; `contacts` allows null scope for global entries. Create takes Valibot-validated `input` and update takes `{ id, patch }`, each mutation audit-logs and publishes a domain event.

## Features

### Addresses

```ts
await p.masters.addresses.create({
  entityType: "organization",
  entityId,
  line1,
  city,
  state,
  postalCode,
  country,
  label,
});
await p.masters.addresses.get({ id });
await p.masters.addresses.update({ id, patch: { city, state } });
await p.masters.addresses.delete({ id });
await p.masters.addresses.list({ entityType: "organization", entityId });
```

Country is ISO 3166-1 alpha-2, normalized uppercase.

### Contacts

```ts
await p.masters.contacts.create({
  entityType: "organization",
  entityId,
  name,
  type: "insurer",
  email,
});
await p.masters.contacts.create({ input: { firstName, lastName, email, phone, company, title } }); // global when entityType/entityId omitted
await p.masters.contacts.get({ id });
await p.masters.contacts.update({ id, patch: { phone } });
await p.masters.contacts.list({ entityType: "organization", entityId });
await p.masters.contacts.remove({ id, input: { reason: "Left the project" } }); // soft-remove with reason
await p.masters.contacts.delete({ id }); // hard delete
```

Global contacts have `entity_type` / `entity_id` null.

### Entities

```ts
await p.masters.entities.create({
  name,
  type: "hospital",
  industry: "Healthcare",
  taxId,
  timezone: "Asia/Kolkata",
});
await p.masters.entities.get({ id });
await p.masters.entities.update({ id, patch: { status: "archived" } });
await p.masters.entities.delete({ id });
await p.masters.entities.list({ filters: { type, status, search } });
```

`code` is unique per tenant. Status `active ↔ inactive → archived` (terminal).

### Org branches

```ts
await p.masters.orgBranches.create({
  name,
  code: "HQ-001",
  type: "headquarters",
  parentOrgBranch: parentId,
});
await p.masters.orgBranches.get({ id });
await p.masters.orgBranches.list({ filters: { type, parentOrgBranch } });
await p.masters.orgBranches.tree({ id }); // subtree rooted at id
await p.masters.orgBranches.update({ id, patch: { name, capacity } });
```

`code` is unique. `parent_org_branch` is self-referential; root rows have `null`.

### Payment methods

```ts
await p.masters.paymentMethods.create({
  entityType: "entity",
  entityId,
  name: "Business UPI",
  type: "upi",
  upiId: "business@okhdfcbank",
  direction: "both",
});
await p.masters.paymentMethods.get({ id });
await p.masters.paymentMethods.update({ id, patch: { name } });
await p.masters.paymentMethods.delete({ id });
await p.masters.paymentMethods.activate({ id });
await p.masters.paymentMethods.deactivate({ id });
await p.masters.paymentMethods.setPrimary({ id }); // one primary per (entityType, entityId, direction)
await p.masters.paymentMethods.list({ entityType, entityId, filters: { type, direction, status } });
```

Card data is masked only (`card_brand`, `card_last4`, expiry). `setPrimary` clears other primaries in scope.

### Settings

```ts
await p.masters.settings.set({ key: "org.branding", value: { accentColor: "#0EA5E9" } });
await p.masters.settings.set({ key: "home_dashboard", value: dashboardId }); // per-user when key not org.*
await p.masters.settings.get({ key: "org.branding" });
```

`org.*` keys are tenant-wide (`user_id` null); other keys are per-user. `set` upserts.

### Units of measure

```ts
await p.masters.unitsOfMeasure.create({
  name: "Kilogram",
  code: "kg",
  category: "mass",
  symbol: "kg",
  isBaseUnit: true,
});
await p.masters.unitsOfMeasure.create({
  name: "Gram",
  code: "g",
  category: "mass",
  isBaseUnit: false,
  baseUnitId: kgId,
  conversionFactor: 0.001,
});
await p.masters.unitsOfMeasure.get({ id });
await p.masters.unitsOfMeasure.update({ id, patch: { symbol } });
await p.masters.unitsOfMeasure.delete({ id }); // blocked if referenced as base_unit_id
await p.masters.unitsOfMeasure.list({ filters: { category, isActive } });
```

One base unit per category; invariant enforced by workflow step.

### Labels

```ts
await p.masters.labels.create({
  name: "priority",
  color: "#EF4444",
  scopeType: "task",
  scopeId: projectId,
});
await p.masters.labels.get({ id });
await p.masters.labels.update({ id, patch: { color } });
await p.masters.labels.delete({ id });
await p.masters.labels.list({ filters: { scopeType, scopeId, search } });
await p.masters.labels.apply({ input: { labelId, entityId, entityType: "task", appliedBy } });
await p.masters.labels.remove({ entityId, entityType: "task", labelId });
await p.masters.labels.listByLabel({ labelId }); // entities carrying the label
```

Scoped labels: `scopeType` / `scopeId` nullable; global when both null. `apply` is idempotent via `onConflictDoNothing`.

### Connections

```ts
await p.masters.connections.create({
  entityType,
  entityId,
  name,
  type: "api_key",
  baseUrl: "https://api.example.com",
  credential: { apiKey: "..." },
});
await p.masters.connections.get({ id });
await p.masters.connections.update({ id, patch: { name, status: "inactive" } });
await p.masters.connections.delete({ id });
await p.masters.connections.check({ id }); // tests base_url, updates last_tested_at
await p.masters.connections.rotateCredential({ id, credential: { apiKey: "..." } });
await p.masters.connections.list({ entityType, entityId });
```

Credentials are stored in `kvStore` under `credential_ref`; plaintext never persists in the row. Requires `$initialize` `kvStore` unit.
