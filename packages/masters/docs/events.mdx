27 domain events across 8 groups, published as plain string topics. `masters:contact_created` replaces `organization:connection_created` for the compliance insurer flow.

## Event Map

### Contact Events

| Event                     | Payload                                          | Trigger              |
| ------------------------- | ------------------------------------------------ | -------------------- |
| `masters:contact_created` | `{ contact: { id, name, type }, entityType }`    | Contact created      |
| `masters:contact_updated` | `{ contact: { id, name }, changes, entityType }` | Contact updated      |
| `masters:contact_removed` | `{ contactId, entityId, entityType, reason }`    | Contact soft-removed |

`entityType`/`entityId` are `null` for global contacts. DMS revokes shares on `masters:contact_removed`.
