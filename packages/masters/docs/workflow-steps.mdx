Reusable steps composed via `ctx.step.run()`. Fetch steps load a row by `id`; invariant steps enforce UOM rules.

## Fetch Steps

All built on the `defineFetchByIdStep` factory (`workflow-steps/fetch-by-id.ts`). Input `{ id }`; throws `<Label> with id "<id>" not found` when missing.

| Step                     | Name                            | Used by                                                                          |
| ------------------------ | ------------------------------- | -------------------------------------------------------------------------------- |
| `fetchAddressStep`       | `masters-fetch-address`         | addresses `get`, `update`, `delete`                                              |
| `fetchContactStep`       | `masters-fetch-contact`         | contacts `get`, `update`, `remove`, `delete`                                     |
| `fetchConnectionStep`    | `masters-fetch-connection`      | connections `get`, `update`, `delete`, `check`, `rotateCredential`               |
| `fetchEntityStep`        | `masters-fetch-entity`          | entities `get`, `update`, `delete`                                               |
| `fetchLabelStep`         | `masters-fetch-label`           | labels `get`, `update`, `delete`, `apply`, `remove`                              |
| `fetchOrgBranchStep`     | `masters-fetch-org-branch`      | orgBranches `get`, `update`, `tree`                                              |
| `fetchPaymentMethodStep` | `masters-fetch-payment-method`  | paymentMethods `get`, `update`, `delete`, `activate`, `deactivate`, `setPrimary` |
| `fetchUnitOfMeasureStep` | `masters-fetch-unit-of-measure` | unitsOfMeasure `get`, `update`, `delete`                                         |

```ts title="src/workflow-steps/fetch-by-id.ts"
export function defineFetchByIdStep<TRow>({
  idColumn,
  label,
  stepName,
  table,
}: FetchByIdStepInput) {
  return WorkflowStep.name(stepName)
    .input(object({ id: string() }))
    .handler(async ({ id }, ctx) => {
      const [row] = (await ctx.db.select().from(table).where(eq(idColumn, id)).limit(1)) as TRow[];
      if (!row) throw new Error(`${label} with id "${id}" not found.`);
      return row;
    });
}

// usage — one line per entity
export const fetchLabelStep = defineFetchByIdStep<MasterLabel>({
  idColumn: masterLabel.id,
  label: "Label",
  stepName: "masters-fetch-label",
  table: masterLabel,
});
```

## Invariant Steps

| Step                                                                     | Input                                                                                                                                                                                                                                  | Used by                           |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| `assertBaseUnitInvariantStep` (`masters-assert-uom-base-unit-invariant`) | `{ category, isBaseUnit, baseUnitId, conversionFactor, excludeId? }` — base units must not reference another base or define a factor and must be unique per category; derived units must reference their category's base with a factor | unitsOfMeasure `create`, `update` |
| `assertNoReferencingUnitsStep` (`masters-assert-uom-no-references`)      | `{ id }` — throws when another unit references it as `base_unit_id`                                                                                                                                                                    | unitsOfMeasure `delete`           |

## Access Helpers

No plain-function access helpers — all guards are `WorkflowStep`s run via `ctx.step.run()`. Invariant checks are the only shared steps beyond fetches; label/org-branch access is enforced inline in each workflow (scope checks, not reusable helpers).
