The Workspace module exposes `dashboards`, `schedules`, `drafts`, `filterViews`, `pins`, `recent`, `search`, and `widgets` via `p.workspace` (`$name = "workspace"`).

Workflows validate with Valibot; `create` takes `{ input }`, `update` takes `{ id, patch }` where `undefined` leaves the column untouched. Mutations write an audit entry and publish a domain event.

## Drafts

Lifecycle with approval, trash, and threaded comments.

```ts
await p.workspace.drafts.create({
  input: { title: "Q3 offer", body: "...", targetDomain: "dms:file" },
});
await p.workspace.drafts.update({ id, patch: { title: "Q3 offer v2" } });
await p.workspace.drafts.submit({ id });
await p.workspace.drafts.approve({ id });
await p.workspace.drafts.reject({ id, input: { rejectionReason: "needs revision" } });
await p.workspace.drafts.publish({ input: { id, targetDomain: "dms:file" } });
await p.workspace.drafts.reopen({ id });
await p.workspace.drafts.trash({ id });
await p.workspace.drafts.restore({ id });
await p.workspace.drafts.duplicate({ id });
await p.workspace.drafts.delete({ id });
await p.workspace.drafts.get({ id });
await p.workspace.drafts.list({ filters: { status: "draft", search, limit: 20, offset: 0 } });
await p.workspace.drafts.addComment({ input: { draftId: id, content: "looks good" } });
await p.workspace.drafts.listComments({ draftId: id });
await p.workspace.drafts.removeComment({ id: commentId });
```

## Dashboards

Named collections of widgets over a grid layout.

```ts
const dash = await p.workspace.dashboards.create({
  input: { name: "Pipeline", layout: [{ widgetId, x: 0, y: 0, w: 6, h: 2 }] },
});
await p.workspace.dashboards.update({ id: dash.id, patch: { name: "Pipeline v2" } });
await p.workspace.dashboards.get({ id: dash.id });
await p.workspace.dashboards.list({ filters: { search, limit: 20, offset: 0 } });
await p.workspace.dashboards.duplicate({ id: dash.id });
const snapshot = await p.workspace.dashboards.export({ id: dash.id });
await p.workspace.dashboards.import({ input: snapshot });
await p.workspace.dashboards.delete({ id: dash.id });
```

## Widgets

Declarative widgets on a dashboard; inherit dashboard access.

```ts
await p.workspace.widgets.add({
  input: {
    dashboardId,
    title: "Revenue",
    type: "metric",
    domain: "dms:file",
    config: { aggregation: "count" },
    filter: [],
  },
});
await p.workspace.widgets.update({ id: widgetId, patch: { title: "Revenue v2" } });
await p.workspace.widgets.move({ id: widgetId, input: { layout: { x: 1, y: 0 } } });
await p.workspace.widgets.refresh({ id: widgetId, input: { error: null } });
await p.workspace.widgets.get({ id: widgetId });
await p.workspace.widgets.list({ dashboardId });
await p.workspace.widgets.remove({ id: widgetId });
```

## Schedules

Per-dashboard cron delivery.

```ts
const sched = await p.workspace.schedules.create({
  input: { dashboardId, cron: "0 8 * * *", config: { recipients: ["a@b.com"], format: "pdf" } },
});
await p.workspace.schedules.update({ id: sched.id, patch: { cron: "0 9 * * *" } });
await p.workspace.schedules.pause({ id: sched.id });
await p.workspace.schedules.resume({ id: sched.id });
await p.workspace.schedules.markRun({ id: sched.id, input: { at: new Date().toISOString() } });
await p.workspace.schedules.get({ id: sched.id });
await p.workspace.schedules.list({ filters: { dashboardId } });
await p.workspace.schedules.delete({ id: sched.id });
```

Cron registers `workspace:delivery_schedule:<id>` and emits `workspace:delivery_due`.

## Filter Views

Saved filter/sort/group configurations.

```ts
const view = await p.workspace.filterViews.create({
  input: { name: "My invoices", domain: "dms:file", conditions: [], sort: [] },
});
await p.workspace.filterViews.update({ id: view.id, patch: { name: "My invoices v2" } });
await p.workspace.filterViews.get({ id: view.id });
await p.workspace.filterViews.list({ filters: { domain: "dms:file" } });
await p.workspace.filterViews.duplicate({ id: view.id });
await p.workspace.filterViews.getDefault({ domain: "dms:file" });
await p.workspace.filterViews.setDefault({ id: view.id });
await p.workspace.filterViews.delete({ id: view.id });
```

## Pins

Per-user sidebar shortcuts.

```ts
await p.workspace.pins.create({ input: { itemId, itemType: "dashboard" } });
await p.workspace.pins.list({ filters: { itemType: "dashboard" } });
await p.workspace.pins.delete({ id: pinId });
```

## Recent

Per-user recent items bounded by `maxRecentItems`.

```ts
await p.workspace.recent.touch({ input: { itemId, itemType: "draft" } });
await p.workspace.recent.list({ limit: 20 });
```

## Search

Access-scoped quick search over drafts and dashboards.

```ts
const res = await p.workspace.search.quick({ input: { query: "INV" } });
// { dashboards: [{ id, name, access }], drafts: [{ id, title, status, access }] }
```
