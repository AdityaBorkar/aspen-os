All events are published as plain string topics on `PubSubUnit` (`ctx.pubsub.publish(topic, payload)`), typed via `WorkspaceEventMap`.

## Drafts

| Event                             | Payload                                                       |
| --------------------------------- | ------------------------------------------------------------- |
| `workspace:draft_created`         | `{ draftId, ownerId, access }`                                |
| `workspace:draft_updated`         | `{ draftId, changes }`                                        |
| `workspace:draft_submitted`       | `{ draftId, submittedBy }`                                    |
| `workspace:draft_approved`        | `{ draftId, approvedBy }`                                     |
| `workspace:draft_rejected`        | `{ draftId, rejectedBy, rejectionReason }`                    |
| `workspace:draft_published`       | **full draft row** — hosts create the target entity from this |
| `workspace:draft_reopened`        | `{ draftId }`                                                 |
| `workspace:draft_trashed`         | `{ draftId }`                                                 |
| `workspace:draft_restored`        | `{ draftId }`                                                 |
| `workspace:draft_duplicated`      | `{ draftId, duplicateId }`                                    |
| `workspace:draft_commented`       | `{ draftId, commentId, authorId }`                            |
| `workspace:draft_comment_removed` | `{ draftId, commentId }`                                      |
| `workspace:draft_deleted`         | `{ draftId }`                                                 |

## Consumer guidance

- **`workspace:draft_published`** — the host subscribes to create the target entity (`targetDomain`/`targetEntityType` on the row) and backfill `targetEntityId`.
- **`workspace:schedule_due`** — the host subscribes to render and deliver (email/PDF/export). If no consumer is registered, pg-boss **silently drops** the message — the platform health check flags produced-but-unsubscribed topics.
- **`workspace:watch_*`** — workspace only persists subscriptions and emits the events; a future `notifications` module consumes them.
