The module owns **10 tenant tables** and **4 pgEnums**. All are `tenant_schemas` with the `workspace_` prefix — there are no control-plane tables. IDs are text `uuidv7` PKs; timestamps are `timestamptz`; no DB-level foreign keys (soft FKs by naming convention).

## Enums

| Enum                     | Column(s)                                                                            | Values                                                    |
| ------------------------ | ------------------------------------------------------------------------------------ | --------------------------------------------------------- |
| `workspace_access`       | `workspace_draft.access`, `workspace_view.access`, `workspace_dashboard.access`      | `personal`, `global`                                      |
| `workspace_draft_status` | `workspace_draft.status`                                                             | `draft`, `submitted`, `approved`, `rejected`, `published` |
| `workspace_widget_type`  | `workspace_widget.type`                                                              | `metric`, `breakdown`, `list`, `embed`                    |
| `workspace_item_type`    | `workspace_pin.item_type`, `workspace_recent.item_type`, `workspace_watch.item_type` | `draft`, `view`, `dashboard`                              |

## Tables

### `workspace_draft`

Saved, unpublished content with an optional approval lifecycle and soft-delete trash.

| Column               | Type                          | Description                                       |
| -------------------- | ----------------------------- | ------------------------------------------------- |
| `access`             | enum `workspace_access`       | `personal` (default) or `global`                  |
| `approved_at`        | timestamptz                   | set by `approve`                                  |
| `approved_by`        | text                          | set by `approve`                                  |
| `body`               | text                          | markdown/text content, default `''`               |
| `created_at`         | timestamptz                   |                                                   |
| `deleted_at`         | timestamptz                   | set by `trash`, cleared by `restore`              |
| `id`                 | text PK (`uuidv7`)            |                                                   |
| `metadata`           | jsonb                         | opaque — attachment refs, structured fields       |
| `notes`              | text                          | free-form annotation                              |
| `owner_id`           | text                          | creating user                                     |
| `published_at`       | timestamptz                   | set by `publish`                                  |
| `published_by`       | text                          | set by `publish`                                  |
| `rejected_at`        | timestamptz                   | set by `reject`                                   |
| `rejected_by`        | text                          | set by `reject`                                   |
| `rejection_reason`   | text                          | required by `reject`                              |
| `status`             | enum `workspace_draft_status` | `draft` (default)                                 |
| `submitted_at`       | timestamptz                   | set by `submit`                                   |
| `submitted_by`       | text                          | set by `submit`                                   |
| `target_domain`      | text                          | what the draft becomes on publish (`dms:file`, …) |
| `target_entity_id`   | text                          | recorded after the host creates the target entity |
| `target_entity_type` | text                          | entity type within the domain                     |
| `title`              | text                          | required                                          |
| `updated_at`         | timestamptz                   |                                                   |

Indexes: `idx_workspace_draft_owner`, `idx_workspace_draft_status`, `idx_workspace_draft_access`.

## Relationships

```text
workspace_draft 1:N workspace_draft_comment (draft_id)
workspace_dashboard 1:N workspace_widget (dashboard_id)
workspace_dashboard 1:N workspace_schedule (dashboard_id)
workspace_widget N:1 workspace_view (view_id — datasource reuse, soft FK)
pin / recent / watch  ── item_type + item_id ──▶ any workspace entity (draft/view/dashboard)
```

## Usage

```ts
// Query with access scoping (list) — same predicate as access-service
await db
  .select()
  .from(workspaceDraft)
  .where(or(eq(workspaceDraft.access, "global"), eq(workspaceDraft.ownerId, actorId)));
```
