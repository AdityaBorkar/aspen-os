Workflow groups via `p.comms`: `channels`, `providers`, `notifications`, `preferences`, `templates`, `settings`, `messages`, plus the lazy `ensureDefaults` helper. `channels`, `providers`, and `notifications` are getters binding `kvStore`/`db` factories; the others are plain workflow objects.

Scoped channel defaults use `(type, entityType, entityId)`; create takes Valibot `{ input }`, update takes `{ input: { id, ... } }`, get/list take `{ input: ... }`. Each mutation writes an audit entry and publishes a `comms.*` event.

## Features

### Channels

Access: `p.comms.channels`

Tenant BYOC channels (sender endpoints). `create` stores the credential in the tenant kvStore and inserts the row as `inactive`.

```ts
const channel = await p.comms.channels.create({
  input: {
    name: "SES Mail",
    type: "email",
    senderAddress: "noreply@acme.com",
    entityType: "organization",
    entityId,
    credential: { apiKey: "..." },
  },
});
await p.comms.channels.test({ input: { id: channel.id, recipientAddress: "ops@acme.com" } });
await p.comms.channels.activate({ input: { id: channel.id } });
await p.comms.channels.setDefault({ input: { id: channel.id } }); // requires active + verifiedAt
await p.comms.channels.rotateCredential({
  input: { id: channel.id, credential: { apiKey: "..." } },
});

await p.comms.channels.get({ input: { id: channel.id } });
await p.comms.channels.list({
  input: { filters: { type: "email", source: "tenant", status: "active" } },
});
await p.comms.channels.update({ input: { id: channel.id, name: "Primary SES" } });
await p.comms.channels.deactivate({ input: { id: channel.id } });
await p.comms.channels.delete({ input: { id: channel.id } }); // rejected while queued/sending messages reference it
await p.comms.channels.ensureDefaults({ input: { entityId, entityType: "organization" } });
```

### Providers

Access: `p.comms.providers`

Host delivery capability registry (control-plane, host-admin). Runs in the global tenant context.

```ts
const provider = await p.comms.providers.create({
  input: {
    name: "Host SES",
    kind: "ses",
    credential: { accessKeyId: "..." },
    defaultSenderAddress: "noreply@aspenos.com",
  },
});
await p.comms.providers.activate({ input: { id: provider.id } });
await p.comms.providers.deactivate({ input: { id: provider.id } });
await p.comms.providers.get({ input: { id: provider.id } });
await p.comms.providers.list({ input: { filters: { kind: "ses", isActive: true } } });
await p.comms.providers.update({ input: { id: provider.id, name: "Host SES v2" } });
```

### Notifications

Access: `p.comms.notifications`

The in-app inbox + notification intent. `notify` is the single entry point for in-app + out-of-band.

```ts
await p.comms.notifications.notify({
  input: {
    recipient: { id: userId, type: "user" },
    sourceModule: "compliance",
    title: "Document expiring in 7 days",
    type: "document_expiring",
  },
});
await p.comms.notifications.getInbox({ input: { filters: { unreadOnly: true } } });
await p.comms.notifications.markRead({ input: { id: notificationId } });
await p.comms.notifications.markUnread({ input: { id: notificationId } });
await p.comms.notifications.dismiss({ input: { id: notificationId } });
await p.comms.notifications.get({ input: { id: notificationId } });
await p.comms.notifications.list({
  input: { filters: { type: "document_expiring", status: "unread" } },
});
await p.comms.notifications.unreadCount({});
```

`getInbox` is caller-scoped (`recipientId = actorId`), ordered `urgent` → `important` → `normal` then `createdAt` desc.

### Preferences

Access: `p.comms.preferences`

Per-user routing + consent (DPDP/HIPAA opt-outs).

```ts
await p.comms.preferences.set({
  input: { userId, type: "document_expiring", channelType: "email", enabled: false },
});
await p.comms.preferences.get({
  input: { userId, type: "document_expiring", channelType: "email" },
});
await p.comms.preferences.list({ input: { filters: { userId } } });
```

Exact `(userId, type, channelType)` wins; else the `(userId, null, channelType)` default row.

### Templates

Access: `p.comms.templates`

Email/SMS/WhatsApp bodies with `{var}` placeholders. WhatsApp requires `providerTemplateId`.

```ts
await p.comms.templates.create({
  input: {
    name: "document-expiring",
    channelType: "email",
    subject: "Expiring: {name}",
    body: "Hi {name}...",
  },
});
await p.comms.templates.activate({ input: { id: templateId } });
await p.comms.templates.deactivate({ input: { id: templateId } });
await p.comms.templates.get({ input: { id: templateId } });
await p.comms.templates.list({ input: { filters: { channelType: "email", isActive: true } } });
await p.comms.templates.update({ input: { id: templateId, body: "Updated {name}" } });
```

### Settings

Access: `p.comms.settings`

Tenant-wide settings.

```ts
await p.comms.settings.set({ input: { key: "suppressOutOfBand", value: true } });
await p.comms.settings.get({ input: { key: "suppressOutOfBand" } });
```

Keys: `defaultChannels` (`channelType → channelId`), `suppressOutOfBand` (boolean), `hostDefaultSenderAddressOverride` (text).

### Messages

Access: `p.comms.messages`

Delivery outbox (admin). `retry` re-queues a `failed` message.

```ts
await p.comms.messages.get({ input: { id: messageId } });
await p.comms.messages.list({ input: { filters: { status: "failed", channelType: "email" } } });
await p.comms.messages.retry({ input: { id: messageId } });
```
