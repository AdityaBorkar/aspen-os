Workflow groups via `p.comms`: `channels`, `providers`, `notifications`, `preferences`, `templates`, `settings`, `messages`, plus the lazy `ensureDefaults` helper. `channels` and `providers` are getters bound to `kvStore`/`db`; the others are stateless.

Scoped channel defaults use `(type, entityType, entityId)`; create takes Valibot `{ input }`, update takes `{ id, patch }`. Each mutation writes an audit entry and publishes a `comms:*` event.

## Features

### Channels

Access: `p.comms.channels`

Tenant BYOC channels (sender endpoints). `create` stores the credential in the tenant kvStore and inserts the row as `inactive`.

```ts
const channel = await p.comms.channels.create({
  input: {
    name: "SES Mail",
    type: "email",
    senderAddress: "noreply@acme.com",
    credential: { apiKey: "..." },
  },
});
await p.comms.channels.test({ id: channel.id }); // sends verification, sets verifiedAt
await p.comms.channels.activate({ id: channel.id });
await p.comms.channels.setDefault({ id: channel.id }); // requires active + verifiedAt
await p.comms.channels.rotateCredential({ id: channel.id, credential: { apiKey: "..." } });

await p.comms.channels.get({ id: channel.id });
await p.comms.channels.list({ filters: { type: "email", source: "tenant", status: "active" } });
await p.comms.channels.update({ id: channel.id, patch: { name: "Primary SES" } });
await p.comms.channels.deactivate({ id: channel.id });
await p.comms.channels.delete({ id: channel.id }); // rejected while non-terminal messages reference it
await p.comms.channels.ensureDefaults({ input: { entityId, entityType: "organization" } });
```

### Providers

Access: `p.comms.providers`

Host delivery capability registry (control-plane, host-admin). Runs in the global tenant context.

```ts
const provider = await p.comms.providers.create({
  input: {
    name: "Host SES",
    kind: "ses",
    credential: { accessKeyId: "..." },
    defaultSenderAddress: "noreply@aspenos.com",
  },
});
await p.comms.providers.activate({ id: provider.id });
await p.comms.providers.deactivate({ id: provider.id });
await p.comms.providers.get({ id: provider.id });
await p.comms.providers.list({ filters: { kind: "ses", isActive: true } });
await p.comms.providers.update({ id: provider.id, patch: { name: "Host SES v2" } });
```

### Notifications

Access: `p.comms.notifications`

The in-app inbox + notification intent. `notify` is the single entry point for in-app + out-of-band.

```ts
await p.comms.notifications.notify({
  input: {
    recipient: { id: userId, type: "user" },
    sourceModule: "compliance",
    title: "Document expiring in 7 days",
    type: "document_expiring",
  },
});
await p.comms.notifications.getInbox({ input: { filters: { unreadOnly: true } } });
await p.comms.notifications.markRead({ input: { id: notificationId } });
await p.comms.notifications.dismiss({ input: { id: notificationId } });
await p.comms.notifications.get({ id: notificationId });
await p.comms.notifications.list({ filters: { type: "document_expiring", status: "unread" } });
await p.comms.notifications.unreadCount.run({}, { actorId: userId });
```

`getInbox` is caller-scoped (`recipientId = actorId`), ordered `urgent` → `important` → `normal` then `createdAt` desc.

### Preferences

Access: `p.comms.preferences`

Per-user routing + consent (DPDP/HIPAA opt-outs).

```ts
await p.comms.preferences.set({
  input: { userId, type: "document_expiring", channelType: "email", enabled: false },
});
await p.comms.preferences.get({ userId, type: "document_expiring", channelType: "email" });
await p.comms.preferences.list({ filters: { userId } });
```

Exact `(userId, type, channelType)` wins; else the `(userId, null, channelType)` default row.

### Templates

Access: `p.comms.templates`

Email/SMS/WhatsApp bodies with `{var}` placeholders. WhatsApp requires `providerTemplateId`.

```ts
await p.comms.templates.create({
  input: {
    name: "document-expiring",
    channelType: "email",
    subject: "Expiring: {name}",
    body: "Hi {name}...",
    isActive: true,
  },
});
await p.comms.templates.activate({ id: templateId });
await p.comms.templates.deactivate({ id: templateId });
await p.comms.templates.get({ id: templateId });
await p.comms.templates.list({ filters: { channelType: "email", isActive: true } });
await p.comms.templates.update({ id: templateId, patch: { body: "Updated {name}" } });
```

### Settings

Access: `p.comms.settings`

Tenant-wide settings.

```ts
await p.comms.settings.set({ input: { key: "suppressOutOfBand", value: true } });
await p.comms.settings.get({ key: "suppressOutOfBand" });
```

Keys: `defaultChannels` (`channelType → channelId`), `suppressOutOfBand` (boolean), `hostDefaultSenderAddressOverride` (text).

### Messages

Access: `p.comms.messages`

Delivery outbox (admin). `retry` re-queues a `failed` message.

```ts
await p.comms.messages.get({ id: messageId });
await p.comms.messages.list({ filters: { status: "failed", channelType: "email" } });
await p.comms.messages.retry({ id: messageId });
```
