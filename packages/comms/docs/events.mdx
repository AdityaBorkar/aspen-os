The Comms module publishes and consumes domain events as plain string topics via `PubSub`.

<Callout type="warn">
  Pubsub starts lazily: publishing to a topic with no subscriber silently drops the message. Every
  bridge topic below is subscribed in `$prepareRuntime()`; the sweeper needs no subscription because
  it is a cron.
</Callout>

## Consumed (event bridge)

| Topic                           | Producer                      | Handler                                                               |
| ------------------------------- | ----------------------------- | --------------------------------------------------------------------- |
| `calendar:reminder_due`         | calendar reminder dispatcher  | `notify` to `reminder.userId` (`type: reminder_fired`)                |
| `dms:file_expired`              | dms `expiry-scanner`          | `notify` to file `ownerId` (`type: file_expired`)                     |
| `announcement:published`        | hr (planned)                  | one in-app notification per `recipientUserIds` (`type: announcement`) |
| `workspace:delivery_due`        | workspace schedule            | fan-out `notify` per `recipients` (`type: dashboard_delivery`)        |
| `workspace:schedule_due`        | workspace (back-compat alias) | same as `delivery_due`                                                |
| `management:tenant_provisioned` | management                    | warm host default channels (`ensureDefaults`) per tenant              |
| `management:tenant_activated`   | management                    | warm host default channels (`ensureDefaults`) per tenant              |
| `auth:email_otp_requested`      | platform auth                 | inline OTP email via host default email provider                      |

Subscriptions register in `$prepareRuntime()` with Valibot validation; unknown topics no-op.

## Produced (`comms:*`)

| Event                              | Payload                                                              | Trigger                         |
| ---------------------------------- | -------------------------------------------------------------------- | ------------------------------- |
| `comms:channel_created`            | `{ channel: { id, name, type, source, status } }`                    | BYOC channel created            |
| `comms:channel_updated`            | `{ channelId, changes }`                                             | Channel edited                  |
| `comms:channel_status_changed`     | `{ channelId, from, to }`                                            | Activate/deactivate             |
| `comms:channel_credential_rotated` | `{ channelId }`                                                      | `rotateCredential`              |
| `comms:channel_tested`             | `{ channelId, ok, at }`                                              | `channels.test` result          |
| `comms:channel_default_changed`    | `{ channelId, type, isDefault }`                                     | `setDefault` / `ensureDefaults` |
| `comms:provider_created`           | `{ provider: { id, name, kind } }`                                   | Host provider created           |
| `comms:provider_status_changed`    | `{ providerId, isActive }`                                           | Provider activated/deactivated  |
| `comms:notification_created`       | `{ notificationId, type, recipientType, recipientId, channelTypes }` | `notify`                        |
| `comms:notification_read`          | `{ notificationId, userId, at }`                                     | `markRead`                      |
| `comms:notification_dismissed`     | `{ notificationId, userId, at }`                                     | `dismiss`                       |
| `comms:message_queued`             | `{ messageId, channelType, to }`                                     | Out-of-band send enqueued       |
| `comms:message_sent`               | `{ messageId, providerMessageId }`                                   | Provider accepted               |
| `comms:message_delivered`          | `{ messageId, at }`                                                  | Provider receipt (webhook)      |
| `comms:message_failed`             | `{ messageId, attempts, error }`                                     | Terminal failure                |
| `comms:preference_updated`         | `{ userId, type?, channelType, enabled }`                            | `preferences.set`               |
| `comms:template_created`           | `{ templateId, name }`                                               | Template created                |
| `comms:template_updated`           | `{ templateId, name }`                                               | Template updated                |
| `comms:template_activated`         | `{ templateId, name, isActive }`                                     | Template activated              |
| `comms:template_deactivated`       | `{ templateId, name, isActive }`                                     | Template deactivated            |
| `comms:settings_updated`           | `{ changes }`                                                        | `settings.set`                  |
