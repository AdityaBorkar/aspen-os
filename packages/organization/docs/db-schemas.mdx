The Organization module defines 2 tables and 2 enums using Drizzle ORM. Contacts, addresses, bank accounts, connections, and notes moved to the **Masters** module (`@aspen-os/masters`).

## Enums

| Enum                  | Table Column          | Values                                                                       |
| --------------------- | --------------------- | ---------------------------------------------------------------------------- |
| `organization_status` | `organization.status` | `active`, `suspended`, `archived`                                            |
| `branch_type`         | `branch.type`         | `headquarters`, `office`, `warehouse`, `store`, `factory`, `remote`, `other` |

## Tables

### `organization`

The root aggregate — represents a company/organization.

| Column         | Type                | Description                         |
| -------------- | ------------------- | ----------------------------------- |
| `id`           | text (PK)           | UUID                                |
| `name`         | text                | Organization name                   |
| `slug`         | text (unique)       | URL-safe identifier                 |
| `status`       | organization_status | `active` / `suspended` / `archived` |
| `email`        | text                | Contact email                       |
| `phone`        | text                | Contact phone                       |
| `website`      | text                | Website URL                         |
| `address`      | text                | Free-text address                   |
| `logo`         | text                | Storage key for logo                |
| `accent_color` | text                | Hex color (default `#3B82F6`)       |
| `locale`       | text                | Locale (default `en-US`)            |
| `timezone`     | text                | Timezone (default `UTC`)            |
| `metadata`     | jsonb               | Flexible metadata                   |
| `created_at`   | timestamptz         | Creation timestamp                  |
| `updated_at`   | timestamptz         | Last update timestamp               |

### `branch`

Hierarchical branch structure (self-referential parent).

| Column          | Type            | Description              |
| --------------- | --------------- | ------------------------ |
| `id`            | text (PK)       | UUID                     |
| `name`          | text            | Branch name              |
| `code`          | text (unique)   | Branch code              |
| `type`          | branch_type     | Branch type              |
| `is_active`     | boolean         | Active flag              |
| `parent_branch` | text (self-ref) | Parent branch (nullable) |
| `address_line1` | text            | Address line 1           |
| `address_line2` | text            | Address line 2           |
| `city`          | text            | City                     |
| `state`         | text            | State/Province           |
| `postal_code`   | text            | Postal code              |
| `country`       | text            | Country code             |
| `email`         | text            | Contact email            |
| `phone`         | text            | Contact phone            |
| `manager`       | text            | Branch manager           |
| `timezone`      | text            | Timezone                 |
| `opened_date`   | date            | Opened date              |
| `closed_date`   | date            | Closed date              |
| `capacity`      | integer         | Capacity                 |
| `metadata`      | jsonb           | Flexible metadata        |
| `created_at`    | timestamptz     | Creation timestamp       |
| `updated_at`    | timestamptz     | Last update timestamp    |

## Relationships

```text
organization ──1:N──→ branch (hierarchical, self-ref parent_branch)
```

Structured contacts, addresses, and bank accounts for an org/branch are managed via `p.masters.*` with `entityType`/`entityId` scoping.
