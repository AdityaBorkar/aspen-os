The Organization module manages the organization profile (the root business entity) and its hierarchical branches.

<Callout type="info">
  Contacts, addresses, bank accounts, integration connections, and notes now live in the **Masters**
  module (`@aspen-os/masters`) as polymorphic tenant master data. This module depends on `masters`
  and owns only the org profile and branches.
</Callout>
