The hr-core module exposes six workflow groups via `p.hrCore`: `access`, `announcement`, `employee`, `lifecycle`, `position`, and `setup`.

Create inputs are Valibot-validated `{ input: Create*Input }`, update is `{ id, patch: Update*Input }` where `undefined` leaves a column untouched. Every command audit-logs and, where listed, publishes a domain event.

## Features

### Access

Access: `p.hrCore.access`

HR users, RBAC roles, permissions, and branch-scoped grants. `deleteRole` refuses system roles; `getAccessibleBranches` merges direct `hr_user_branch_access` with branch-scoped `hr_user_role` grants; `getUserPermissions` de-duplicates `module:action` pairs.

```ts title="access — user and role"
import { HrCore } from "@aspen-os/hr-core";

await p.hrCore.access.createUser({ input: { employeeId: "EMP-001", userId: "auth-123" } });
await p.hrCore.access.getUserById({ id });
await p.hrCore.access.getUserByEmployeeId({ employeeId: "EMP-001" });
await p.hrCore.access.listUsers({ filters: {} });

await p.hrCore.access.createRole({ input: { name: "HR Manager", description: "Manages HR" } });
await p.hrCore.access.getRoleByName({ name: "HR Manager" });
await p.hrCore.access.assignRoleToUser({ input: { hrUserId, roleId, branchId: null } });
await p.hrCore.access.removeRoleFromUser({ hrUserId, roleId, branchId });
await p.hrCore.access.getUserRoles({ hrUserId });
await p.hrCore.access.getUserRolesForBranch({ hrUserId, branchId });
```

```ts title="access — permissions and branch access"
await p.hrCore.access.createPermission({ input: { module: "employee", action: "view" } });
await p.hrCore.access.listPermissionsByModule({ module: "employee" });
await p.hrCore.access.assignPermissionToRole({ input: { roleId, permissionId } });
await p.hrCore.access.getRolePermissions({ roleId });

await p.hrCore.access.grantBranchAccess({ input: { hrUserId, branchId, accessLevel: "manage" } });
await p.hrCore.access.revokeBranchAccess({ hrUserId, branchId });
await p.hrCore.access.hasBranchAccess({ hrUserId, branchId });
await p.hrCore.access.hasPermission({ hrUserId, module: "employee", action: "view", branchId });
```

### Announcement

Access: `p.hrCore.announcement`

Authoring, audience targeting, scheduling, publishing, pinning, and delivery snapshot.

```ts title="announcement — publish and schedule"
await p.hrCore.announcement.create({
  input: {
    title: "Policy Update",
    body: "New leave policy effective next month",
    channel: "hr",
    priority: "normal",
    requireAcknowledgement: false,
  },
});
await p.hrCore.announcement.create({
  input: {
    title: "Holiday Notice",
    body: "Office closed Monday",
    channel: "custom",
    audience: { type: "departments", ids: ["dept-eng"] },
    scheduleAt: "2026-09-10T09:00:00Z",
  },
});
await p.hrCore.announcement.publish({ id });
await p.hrCore.announcement.schedule({ id, scheduledFor: "2026-09-10T09:00:00Z" });
await p.hrCore.announcement.cancelSchedule({ id });
await p.hrCore.announcement.archive({ id });
await p.hrCore.announcement.restore({ id });
await p.hrCore.announcement.pin({ id });
await p.hrCore.announcement.unpin({ id });
await p.hrCore.announcement.getById({ id });
await p.hrCore.announcement.list({ filters: { status: "published" } });
await p.hrCore.announcement.listRecipients({ announcementId: id });
await p.hrCore.announcement.getStats({ announcementId: id });
```

Publish is idempotent — re-publishing a published announcement returns it without re-emitting `announcement:published`.

### Employee

Access: `p.hrCore.employee`

Employee records, groups, health insurance, and skill maps.

```ts title="employee — CRUD and groups"
await p.hrCore.employee.create({
  input: {
    employeeId: "EMP-001",
    firstName: "Aarav",
    lastName: "Sharma",
    company: "ACME",
    department: "dept-eng",
    designation: "des-swe",
    employmentType: "permanent",
    dateOfJoining: "2024-01-15",
  },
});
await p.hrCore.employee.update({ id, patch: { department: "dept-prod" } });
await p.hrCore.employee.getById({ id });
await p.hrCore.employee.getByEmployeeId({ employeeId: "EMP-001" });
await p.hrCore.employee.list({ filters: { department: "dept-eng", status: "active" } });
await p.hrCore.employee.deactivate({ id });
await p.hrCore.employee.activate({ id });
await p.hrCore.employee.markAsLeft({ id, dateOfLeaving: "2026-03-31" });
await p.hrCore.employee.getOrganizationalChart({ company: "ACME" });

await p.hrCore.employee.createGroup({ input: { name: "Engineering" } });
await p.hrCore.employee.addGroupMember({ input: { groupId, employeeId: "EMP-001" } });
await p.hrCore.employee.removeGroupMember({ groupId, employeeId: "EMP-001" });
await p.hrCore.employee.listGroupMembers({ groupId });
```

```ts title="employee — health insurance and skills"
await p.hrCore.employee.createHealthInsurance({
  input: {
    employeeId: "EMP-001",
    insurer: "ICICI Lombard",
    policyNumber: "POL-123",
    startDate: "2024-01-01",
  },
});
await p.hrCore.employee.listHealthInsuranceByEmployee({ employeeId: "EMP-001" });

await p.hrCore.employee.createSkillMap({
  input: { employeeId: "EMP-001", skill: "TypeScript", proficiency: "advanced" },
});
await p.hrCore.employee.listSkillMapByEmployee({ employeeId: "EMP-001" });
```

### Lifecycle

Access: `p.hrCore.lifecycle`

Onboarding, promotions, transfers, separations, exit interviews, and full-and-final settlements.

```ts title="lifecycle — onboarding and tasks"
await p.hrCore.lifecycle.createOnboarding({
  input: { employeeId: "EMP-001", startDate: "2024-01-15" },
});
await p.hrCore.lifecycle.getOnboardingById({ id });
await p.hrCore.lifecycle.listOnboardings({ filters: {} });
await p.hrCore.lifecycle.createOnboardingTask({
  input: { onboardingId: id, title: "Complete paperwork" },
});
await p.hrCore.lifecycle.completeOnboardingTask({ id, completedBy: "mgr-1" });
await p.hrCore.lifecycle.listOnboardingTasks({ onboardingId: id });
```

```ts title="lifecycle — promotion, transfer, separation"
await p.hrCore.lifecycle.createPromotion({
  input: {
    employeeId: "EMP-001",
    currentDesignation: "SWE-1",
    newDesignation: "SWE-2",
    effectiveDate: "2026-04-01",
  },
});
await p.hrCore.lifecycle.approvePromotion({ id, approvedBy: "mgr-1" });
await p.hrCore.lifecycle.rejectPromotion({
  id,
  rejectedBy: "mgr-1",
  rejectionReason: "Not yet eligible",
});
await p.hrCore.lifecycle.completePromotion({ id });

await p.hrCore.lifecycle.createTransfer({
  input: {
    employeeId: "EMP-001",
    fromDepartment: "dept-eng",
    toDepartment: "dept-prod",
    effectiveDate: "2026-04-01",
  },
});
await p.hrCore.lifecycle.approveTransfer({ id, approvedBy: "mgr-1" });

await p.hrCore.lifecycle.createSeparation({
  input: { employeeId: "EMP-001", exitDate: "2026-06-30" },
});
await p.hrCore.lifecycle.createExitInterview({
  input: { employeeId: "EMP-001", separationId: id, scheduledDate: "2026-06-15T10:00:00Z" },
});
await p.hrCore.lifecycle.createFullAndFinal({
  input: {
    employeeId: "EMP-001",
    separationId: id,
    pendingSalary: "50000",
    leaveEncashment: "10000",
  },
});
await p.hrCore.lifecycle.approveFullAndFinal({ id, approvedBy: "mgr-1" });
await p.hrCore.lifecycle.markFullAndFinalPaid({ id, paymentEntry: "PE-001" });
```

`deleteOnboarding` and `deleteSeparation` cascade-delete their tasks first.

### Position

Access: `p.hrCore.position`

Job slots, dated assignments with history, and structure views.

```ts title="position — slots and assignments"
await p.hrCore.position.create({
  input: { name: "Tech Lead", department: "dept-eng", branch: "branch-hq", headcount: 2 },
});
await p.hrCore.position.assignEmployee({
  positionId,
  employeeId: "EMP-001",
  input: { fromDate: "2024-01-15", isPrimary: true },
});
await p.hrCore.position.transferAssignment({ assignmentId, input: { toPositionId: "pos-2" } });
await p.hrCore.position.unassignEmployee({ assignmentId, toDate: "2026-03-31" });
await p.hrCore.position.getPositionHistory({ positionId });
await p.hrCore.position.getEmployeePositionHistory({ employeeId: "EMP-001" });
await p.hrCore.position.getCurrentPositions({ employeeId: "EMP-001" });
await p.hrCore.position.deactivate({ id });
await p.hrCore.position.activate({ id });
```

```ts title="position — structure views"
await p.hrCore.position.getOrgTree({ company: "ACME" });
await p.hrCore.position.getPositionTree({ positionId });
await p.hrCore.position.getDirectReports({ managerId: "EMP-001" });
await p.hrCore.position.getSubordinates({ managerId: "EMP-001", depth: 3 });
await p.hrCore.position.getPeers({ employeeId: "EMP-001" });
await p.hrCore.position.getTeam({ employeeId: "EMP-001" });
```

### Setup

Access: `p.hrCore.setup`

HR/payroll settings, employment types, departments (tree ops), designations, grades, and holiday lists.

```ts title="setup — settings and departments"
await p.hrCore.setup.getHrSettings({});
await p.hrCore.setup.updateHrSettings({ patch: { defaultHolidayList: "hl-1" } });
await p.hrCore.setup.getPayrollSettings({});
await p.hrCore.setup.updatePayrollSettings({ patch: { fiscalYearStart: "2024-04-01" } });

await p.hrCore.setup.createDepartment({ input: { code: "eng", name: "Engineering" } });
await p.hrCore.setup.moveDepartment({ id, newParentId: "dept-prod" });
await p.hrCore.setup.setDepartmentHead({ id, employeeId: "EMP-001" });
await p.hrCore.setup.getDepartmentTree({});
await p.hrCore.setup.getDepartmentSubtree({ id, depth: 2 });
await p.hrCore.setup.listPositionsByDepartment({ departmentId: "dept-eng", includeSubtree: true });
await p.hrCore.setup.deleteDepartment({ id });
```

```ts title="setup — catalog and holidays"
await p.hrCore.setup.createDesignation({ input: { name: "Software Engineer" } });
await p.hrCore.setup.createEmploymentType({ input: { name: "Permanent" } });
await p.hrCore.setup.createEmployeeGrade({ input: { name: "G7" } });
await p.hrCore.setup.createHolidayList({ input: { name: "India 2026", year: 2026 } });
await p.hrCore.setup.createHoliday({
  input: { holidayListId: "hl-1", name: "Republic Day", date: "2026-01-26", type: "public" },
});
await p.hrCore.setup.listHolidaysByList({ holidayListId: "hl-1" });
```

`updateHrSettings` and `updatePayrollSettings` are upserts; department codes are uppercased on write.

Events emitted by these workflows: [Events](/docs/hr-core/events). Tables touched: [DB Schemas](/docs/hr-core/db-schemas).
