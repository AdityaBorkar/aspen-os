Control-plane and tenant tables (`hr_` and domain prefixes). Shared columns `id` (text PK, UUIDv7), `created_at`, `updated_at` (timestamptz) on every table unless noted; no hard FKs — all cross-row links are soft text FKs validated in workflows.

| `hr_employment_type`       | `contract`, `freelance`, `intern`, `part_time`, `permanent`, `temporary`                  |

### `hr_user` — control-plane

## Relationships

All FKs are soft (logical, no DB constraints); invariants enforced in workflows.

```mermaid
flowchart LR
  EMP[employee] -->|reports_to| EMP
  EGM[employee_group_member] -->|group_id| EG[employee_group]
  EGM -->|employee_id| EMP
  EHI[employee_health_insurance] -->|employee_id| EMP
  ESM[employee_skill_map] -->|employee_id| EMP
  EOB[employee_onboarding] -->|employee_id| EMP
  EPT[employee_promotion] -->|employee_id| EMP
  EST[employee_separation] -->|employee_id| EMP
  ETR[employee_transfer] -->|employee_id| EMP
  OT[onboarding_task] -->|onboarding_id| EOB
  ST[separation_task] -->|separation_id| EST
  EI[exit_interview] -->|employee_id| EMP
  EI -->|separation_id| EST
  FFS[full_and_final_statement] -->|employee_id| EMP
  HRP[hr_position] -->|reports_to_position| HRP
  HRA[hr_position_assignment] -->|position_id| HRP
  HRA -->|employee_id| EMP
  HRA -. is_primary unique per employee .-> EMP
  HOL[holiday] -->|holiday_list_id| HL[holiday_list]
  HRP_ann[hr_announcement_recipient] -->|announcement_id| HRANN[hr_announcement]
  HUR[hr_user_role] -->|hr_user_id| HRU[hr_user]
  HUR -->|role_id| HRROLE[hr_role]
  HRP2[hr_role_permission] -->|role_id| HRROLE
  HRP2 -->|permission_id| HRPERM[hr_permission]
  HUBA[hr_user_branch_access] -->|hr_user_id| HRU
  DEPT[department] -->|parent_department| DEPT
```
