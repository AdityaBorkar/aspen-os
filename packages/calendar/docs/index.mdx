---
title: Calendar
description: One organization-wide calendar of events and reminders with organization, group, or user audiences.
icon: IconCalendarClock
---

The Calendar module owns two time-domain surfaces for a single organization-wide calendar: events (with recurrence, attendees, timezone) and the platform's single polymorphic reminder surface. Every item carries an audience — the whole organization, an employee group, or one user.
