Create, prepare, run, and tear down a platform — end-to-end inside `p.run(tenantId, fn)`.

## Prerequisites

- `DatabaseConfig` for `db` (control-plane DB)
- `AuthConfig`, `KvStoreConfig`, `LogConfig`, `PubSubConfig`, `RpcConfig`, `StorageConfig`
- Domain modules constructed via `Module.create(config)`

## Step 1: Create the Platform

Pass a config and a module **array** to the static factory — no `new`, no `registerModule()`.

```ts
import { IsolatedTenantPlatform } from "@aspen-os/platform/server";
import { Organization } from "@aspen-os/organization";
import { Compliance } from "@aspen-os/compliance";

const organization = Organization.create({ country: "INDIA" });
const compliance = Compliance.create({ country: "INDIA" });

const p = IsolatedTenantPlatform.create(
  {
    auth: authConfig,
    db: dbConfig,
    kvStore: kvConfig,
    logs: logConfig,
    pubsub: pubsubConfig,
    rpc: rpcConfig,
    storage: storageConfig,
  },
  [organization, compliance],
);
```

There is a single platform class — `IsolatedTenantPlatform` (control-plane DB + per-tenant DBs, physical isolation). There is no `tenancy` config field.

## Step 2: Prepare Infrastructure

Push schemas, apply ACL, and wire module runtimes.

```ts
await p.$prepareInfra();
```

Runs `db.$prepareInfra()` + `auth.$prepareInfra()` first (failures are fatal), then remaining units in parallel, merges `ModuleInfra` (`db` schemas + `auth.acl`, collisions throw, ACL deduped), calls `db.$prepareInfra()` (control-plane push), `auth.applyModuleAcl()`, then each module's `$prepareRuntime()` in parallel via `run("$global", ...)`, then iterates `resolver.list()` to call `mod.$prepareTenant` per tenant in parallel (failures aggregated, not logged-and-swallowed).

## Step 3: Run in Request Context

`run(tenantId, fn)` exposes units via `AsyncLocalStorage`. Pass `"$global"` for control-plane work.

```ts
import { getContext } from "@aspen-os/platform/server";

await p.run("$global", async () => {
  const { audit, auth, db, log, pubsub } = getContext();
  const result = await db.select().from(organizations);
  await pubsub.publish("organization.created", { organization });
});
```

Inside `fn` you have `db` (stable Proxy per-request), `pubsub`, `auth` (AuthUnit), `audit`, `log`. Non-global tenant ids resolve `getTenantDb(tenantId)` under `fn`.

## Step 4: Use Units

Call unit APIs inside `run()` or via the proxy `p.*`.

```ts
await p.run("$global", async () => {
  // Auth
  await p.auth.rest.user.create({ email: "user@example.com", password: "...", name: "John Doe" });
  await p.auth.rest.session.validate({ token });
  await p.auth.rest.user.role.assign({ userId, roleName: "admin" });

  // Storage + KV
  const file = await p.storage.upload({
    key: "documents/report.pdf",
    body: buffer,
    contentType: "application/pdf",
  });
  const url = await p.storage.getSignedGetUrl("documents/report.pdf", { expiresIn: 3600 });
  await p.kvStore.getOrSet("expensive:query", async () => runExpensiveQuery(), 3600);

  // PubSub (always subscribe before publish)
  await p.pubsub.subscribe("organization.created", async (message) => console.log(message.data));
  await p.pubsub.publish("organization.created", { organization });
  await p.pubsub.schedule({
    topic: "compliance.weekly-summary",
    cron: "0 9 * * 1",
    data: {},
    options: { tz: "Asia/Kolkata" },
  });
});
```

<Callout type="info">
  `publish()` auto-creates the queue on first use and retries, so publishing without a `subscribe()`
  consumer queues durably instead of throwing. Use `p.pubsub.getUnsubscribedProducedTopics()` to
  surface topics with no consumer.
</Callout>

## Step 5: Check Health & Clean Up

Probe liveness, then shut down pools and workers.

```ts
await p.pubsub.getQueueSize("some.topic"); // works on unregistered topics — connectivity probe
p.pubsub.getUnsubscribedProducedTopics(); // produced topics with no subscriber
const result = await p.rpc.server.handle(request, { db: p.db.db, pubsub: p.pubsub });
// router.health.check → { status: "ok" }

await p.$cleanup(); // Promise.allSettled → AggregateError if any fail
```

`$cleanup` stops pg-boss, ends pools, and clears tenant caches; failures from modules + units are aggregated, not per-item logged.

## Use It

```ts
const p = IsolatedTenantPlatform.create(config, [Organization.create({ country: "INDIA" })]);
await p.$prepareInfra();
await p.run("$global", async () => {
  const { db } = getContext();
  await db.insert(organizations).values({ name: "Acme" });
});
await p.$cleanup();
```

| Convention             | Value                                                                 |
| ---------------------- | --------------------------------------------------------------------- |
| Control-plane sentinel | `"$global"` — `isGlobalTenantId()` tests it                           |
| Module access          | `p.organization` (proxy by `$name`) or `p.getModule("organization")`  |
| Auth HTTP              | `p.auth.fetchHandler(request)` or `p.auth.service.handler(request)`   |
| Client `run`           | `Platform.run(fn)` — no tenant id, sets `{ auth, logs, rpc }` context |
