This guide walks through creating a custom domain module that follows the platform's conventions. The pattern is derived from the `management` module.

## Overview

A module is a class that implements the `Module` interface and packages domain workflows, database schemas, validation schemas, and event definitions. The platform calls `$initialize(units)` to inject dependencies, `$prepareInfra()` to declare schemas/ACL/events, `$prepareRuntime()` to set up handlers, and `$cleanup()` to clean up.

## File Structure

```text
packages/my-module/
  src/
    index.ts              # Module class + type re-exports
    module.ts             # Module class (implements Module)
    auth.ts               # defineAcl() ACL declaration
    pubsub.ts             # Event constants + typed event interfaces + EventMap type
    types.ts              # Type re-exports from schemas + domain interfaces
    utils/
      constants.ts        # Module-specific enums (as const objects)
      strip-undefined.ts  # stripUndefined helper
    db-schemas/
      index.ts            # control_plane_schemas + tenant_schemas aggregates
      enums.ts            # pgEnum definitions referencing constants
      entity.ts           # Per-entity drizzle pgTable definitions
    schemas/
      index.ts            # Re-exports all schemas + types
      enums.ts            # Valibot enum schemas mirroring constants
      utils.ts            # Shared valibot schema utilities (regex, lengths)
      entity.ts           # Per-entity valibot schemas
    workflows/
      <entity>/
        <verb>.ts           # REST-style folders (task/get.ts, class/field/add.ts)
        <subresource>/<verb>.ts
      utils.ts
      index.ts              # Optional per-entity re-export barrel
  package.json
  tsconfig.json
```

## Step 1: Package Setup

`package.json`:

```json title="package.json"
{
  "name": "@aspen-os/my-module",
  "type": "module",
  "exports": { ".": "./src/index.ts" },
  "dependencies": {
    "@aspen-os/platform": "workspace:*",
    "@aspen-os/constants": "workspace:*",
    "drizzle-orm": "catalog:",
    "valibot": "catalog:"
  }
}
```

<Callout type="info">
  No build step. Package `exports` point at raw `.ts` files. Bun resolves them directly.
  (`@aspen-os/platform`, `@aspen-os/organization`, and `@aspen-os/management` build to `.output/`;
  most modules export raw source.)
</Callout>

## Step 2: Database Schema

Create `src/db-schemas/entity.ts` with Drizzle table and enum definitions. One file per table, plus a shared `enums.ts` for `pgEnum` definitions:

```ts title="src/db-schemas/enums.ts"
import { pgEnum } from "drizzle-orm/pg-core";

import { MY_ENTITY_STATUS } from "../utils/constants";

export const myEntityStatusEnum = pgEnum("my_entity_status", [
  MY_ENTITY_STATUS.ACTIVE,
  MY_ENTITY_STATUS.INACTIVE,
]);
```

```ts title="src/db-schemas/entity.ts"
import { uuidv7 } from "@aspen-os/platform/server";
import { index, jsonb, pgTable, text, timestamp } from "drizzle-orm/pg-core";

import { myEntityStatusEnum } from "./enums";

export const myEntity = pgTable(
  "my_entity",
  {
    id: text("id").primaryKey().$defaultFn(uuidv7),
    name: text("name").notNull(),
    status: myEntityStatusEnum("status").notNull().default("active"),
    metadata: jsonb("metadata"),
    createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp("updated_at", { withTimezone: true }).notNull().defaultNow(),
  },
  (table) => [index("idx_my_entity_status").on(table.status)],
);

export type MyEntity = typeof myEntity.$inferSelect;
export type NewMyEntity = typeof myEntity.$inferInsert;
```

Then aggregate in `src/db-schemas/index.ts`:

```ts title="src/db-schemas/index.ts"
import * as myEntity from "./my-entity";

export { myEntity, myEntityStatusEnum } from "./my-entity";

export const control_plane_schemas = {} as const;

export const tenant_schemas = {
  ...myEntity,
} as const;
```

<Callout type="warn">
  IDs are always `text` with `.primaryKey().$defaultFn(uuidv7)` — never native UUID columns.
  Timestamps use `TIMESTAMPTZ` / `withTimezone: true`. `uuidv7` is exported from
  `@aspen-os/platform/server` (no `sql\`uuidv7()\`` needed in schema files).
</Callout>

## Step 3: Constants & Enums

`src/utils/constants.ts`:

```ts title="src/utils/constants.ts"
export const MY_ENTITY_STATUS = {
  ACTIVE: "active",
  INACTIVE: "inactive",
} as const;

export type MyEntityStatus = (typeof MY_ENTITY_STATUS)[keyof typeof MY_ENTITY_STATUS];
```

`src/schemas/enums.ts` mirrors the constants with valibot `picklist`:

```ts title="src/schemas/enums.ts"
import { picklist } from "valibot";

import { MY_ENTITY_STATUS } from "./utils/constants";

export const MyEntityStatusSchema = picklist(Object.values(MY_ENTITY_STATUS));

export { MY_ENTITY_STATUS } from "./utils/constants";
```

## Step 4: Validation Schemas (Valibot)

`src/schemas/entity.ts`:

```ts title="src/schemas/entity.ts"
import { type InferOutput, nullable, object, optional, pipe, string, minLength } from "valibot";

import { NameSchema } from "./utils";

export const CreateMyEntitySchema = object({
  name: NameSchema,
  status: optional(nullable(string())),
});

export type CreateMyEntityInput = InferOutput<typeof CreateMyEntitySchema>;

export const UpdateMyEntitySchema = object({
  name: optional(NameSchema),
  status: optional(string()),
});

export type UpdateMyEntityInput = InferOutput<typeof UpdateMyEntitySchema>;

export const MyEntityFiltersSchema = object({
  status: optional(string()),
});

export type MyEntityFilters = InferOutput<typeof MyEntityFiltersSchema>;
```

## Step 5: Events

`src/pubsub.ts`:

```ts title="src/pubsub.ts"
export const MY_ENTITY_EVENTS = {
  CREATED: "my-module:entity_created",
  UPDATED: "my-module:entity_updated",
} as const;

export const events = {
  MY_ENTITY_EVENTS,
};

export interface MyEntityCreatedEvent {
  entity: { id: string; name: string };
}

export interface MyEntityUpdatedEvent {
  changes: Record<string, unknown>;
  entity: { id: string; name: string };
}

export type MyEntityEventMap = {
  [MY_ENTITY_EVENTS.CREATED]: MyEntityCreatedEvent;
  [MY_ENTITY_EVENTS.UPDATED]: MyEntityUpdatedEvent;
};

export type MyModuleEventMap = MyEntityEventMap;
```

## Step 6: Auth ACL

`src/auth.ts`:

```ts title="src/auth.ts"
import { defineAcl } from "@aspen-os/platform/server";

export const acl = defineAcl({
  myEntity: ["create", "delete", "read", "update"],
});
```

## Step 7: Workflow

Each workflow is a separate file in REST-style folders (`workflows/<entity>/<verb>.ts`, e.g. `my-entity/create.ts`) using the `Workflow`/`WorkflowStep` builder API. Reusable DB lookups live in `src/workflow-steps/`:

```ts title="src/workflow-steps/fetch-my-entity.ts"
import { WorkflowStep } from "@aspen-os/platform/server";
import { eq } from "drizzle-orm";
import { object } from "valibot";

import { myEntity } from "../../db-schemas";
import { IdSchema } from "../../types";

export const fetchMyEntityStep = WorkflowStep.name("fetch-my-entity")
  .input(object({ id: IdSchema }))
  .handler(async (input, ctx) => {
    const [result] = await ctx.db.select().from(myEntity).where(eq(myEntity.id, input.id)).limit(1);

    if (!result) {
      throw new Error(`My entity with id "${input.id}" not found.`);
    }

    return result;
  });
```

```ts title="src/workflows/my-entity/create.ts"
import { Workflow } from "@aspen-os/platform/server";
import { object } from "valibot";

import { myEntity } from "../db-schemas";
import { MY_ENTITY_EVENTS } from "../pubsub";
import { CreateMyEntitySchema } from "../types";

const CreateInputSchema = object({ input: CreateMyEntitySchema });

export const createMyEntity = Workflow.name("my-entity.create")
  .input(CreateInputSchema)
  .handler(async ({ input }, ctx) => {
    const [result] = await ctx.db
      .insert(myEntity)
      .values({ name: input.name, status: input.status ?? null })
      .returning();

    if (!result) throw new Error("Failed to create my entity.");

    await ctx.audit.write({
      action: "my-entity:created",
      crudAction: "create",
      entityId: result.id,
      entityType: "myEntity",
      newState: { name: result.name },
    });

    await ctx.pubsub.publish(MY_ENTITY_EVENTS.CREATED, {
      entity: { id: result.id, name: result.name },
    });

    return result;
  });
```

Workflows resolve their dependencies from `ctx` at runtime (`ctx.db`, `ctx.audit`, `ctx.pubsub`, `ctx.auth`). Stateless workflow groups are plain `readonly` properties; use a getter only when a workflow must be bound to a unit at construction time (`createX(this.#db)`).

## Step 8: Module Class

`src/module.ts`:

```ts title="src/module.ts"
import type {
  AuthUnit,
  DatabaseUnit,
  Module,
  ModuleInfra,
  PubSubUnit,
} from "@aspen-os/platform/server";

import { acl } from "./auth";
import { control_plane_schemas, tenant_schemas } from "./db-schemas";
import { events } from "./pubsub";
import { createMyEntity } from "./workflows/my-entity/create";
import { getMyEntity } from "./workflows/my-entity/get";

export type MyModuleConfig = {
  // module-specific config options
};

export class MyModule implements Module {
  static create(config: MyModuleConfig): MyModule {
    return new MyModule(config);
  }

  readonly $name = "my-module";
  readonly $dependencies: readonly string[] = [];
  readonly $config: MyModuleConfig;

  #db: DatabaseUnit | null = null;

  constructor(config: MyModuleConfig) {
    this.$config = config;
  }

  $prepareInfra(): ModuleInfra {
    return {
      auth: { acl },
      db: { control_plane_schemas, tenant_schemas },
      events,
    };
  }

  $initialize(units: { db: DatabaseUnit; auth: AuthUnit; pubsub: PubSubUnit }): void {
    this.#db = units.db;
  }

  $prepareRuntime() {}

  $cleanup() {}

  get myEntities() {
    if (!this.#db) throw new Error("MyModule not initialized");
    return {
      create: createMyEntity,
      get: getMyEntity,
    };
  }
}
```

`src/index.ts` re-exports the class, config type, and public types:

```ts title="src/index.ts"
export { MyModule, type MyModuleConfig } from "./module";
export * from "./types";
```

`src/types.ts` re-exports event types/constants and valibot schemas/types:

```ts title="src/types.ts"
export type { MyModuleEventMap } from "./pubsub";
export { MY_ENTITY_EVENTS } from "./pubsub";
export type { CreateMyEntityInput, MyEntityFilters, UpdateMyEntityInput } from "./schemas";
export { CreateMyEntitySchema, MyEntityFiltersSchema, UpdateMyEntitySchema } from "./schemas";
```

## Step 9: Use It

```ts
import { SingleTenantPlatform } from "@aspen-os/platform/server";
import { MyModule } from "@aspen-os/my-module";

const myModule = MyModule.create({});

const p = SingleTenantPlatform.create(config, [myModule]);

await p.$prepareInfra();

await p.run(async () => {
  const entity = await p["my-module"].myEntities.create({
    name: "My Entity",
  });
});
```

## Key Conventions

| Convention                            | Rule                                                                                                                                                   |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Static `create(config)` factory       | Always use a static factory, not `new` directly                                                                                                        |
| `#` prefix for private fields         | `#db: DatabaseUnit \| null = null`                                                                                                                     |
| `module.ts` holds the class           | `index.ts` only re-exports                                                                                                                             |
| `auth.ts` holds the ACL               | `defineAcl({ resource: ["create", ...] })` (was `utils/acl.ts`)                                                                                        |
| `pubsub.ts` holds events              | Constants + interfaces + EventMap (was `pubsub-events.ts` / `event-map.ts`)                                                                            |
| `db-schemas/` per entity              | One `pgTable` per file, `enums.ts` for `pgEnum`s, aggregate in `index.ts`                                                                              |
| `workflows/` REST-style folders       | `Workflow.name("entity.action").input(...).handler(...)`, one file per workflow at `workflows/<entity>/<verb>.ts`, reusable steps in `workflow-steps/` |
| `$name` / `$dependencies` as readonly | Become proxy keys + init ordering                                                                                                                      |
| `$prepareInfra()` returns ModuleInfra | Declares ACL + DB schemas + events                                                                                                                     |
| `$prepareRuntime()`                   | Registers pubsub handlers/schedules                                                                                                                    |
| `$cleanup()` nulls fields             | Unregisters handlers and nulls private fields                                                                                                          |
| Valibot for validation                | Domain module input validation                                                                                                                         |
| Events as `"domain:event_name"`       | Typed via `EventMap`, published as plain strings                                                                                                       |
