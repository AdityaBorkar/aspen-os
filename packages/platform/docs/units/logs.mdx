The `LogUnit` (`$name: "logs"`) buffers entries in memory and flushes to Postgres in batches.

## Configuration

```ts title="src/server/log/types.ts"
interface LogConfig {
  defaultLevel?: LogLevel; // default "info"
  serviceName?: string; // default "app"
}
type LogLevel = "debug" | "info" | "warn" | "error" | "fatal";
```

```ts
const logConfig: LogConfig = { defaultLevel: "info", serviceName: "recruiter-api" };
```

## Features

### Writing

Buffered (capacity 100, flush every 5s; drained on destroy).

```ts
platform.logs.info("User created", { userId: "123" });
platform.logs.error("Database error", new Error("Connection refused"), { service: "db" });
platform.logs.debug("spill"); // dropped if below defaultLevel
```

Levels: `debug(0) < info(1) < warn(2) < error(3) < fatal(4)`.

### Child loggers

Merge context into every entry.

```ts
const requestLogger = platform.logs.child({ requestId: "req-abc-123", userId: "user-456" });
requestLogger.info("Processing request");
requestLogger.error("Validation failed", err);
```

### Querying

```ts
const entries = await platform.logs.query({
  level: "error",
  service: "recruiter-api",
  startTime: new Date("2024-01-01"),
  endTime: new Date(),
  userId: "user-123",
  search: "database",
  limit: 50,
  offset: 0,
});
const stats = await platform.logs.getStats({ service: "recruiter-api", startTime, endTime });
// { total, byLevel: { debug, info, ... }, errorRate }
```

<Callout type="info">
  `query()` and `getStats()` auto-scope to current `tenantId` from request context.
</Callout>

### Entry & Table

```ts title="src/server/log/types.ts"
interface LogEntry {
  id: string;
  level: LogLevel;
  message: string;
  service: string;
  timestamp: Date;
  metadata?: Record<string, unknown>;
  error?: { name; message; stack };
  traceId?: string;
  spanId?: string;
  tenantId?: string;
  userId?: string;
  requestId?: string;
  duration?: number;
}
```

| Column                                         | Type          | Description                           |
| ---------------------------------------------- | ------------- | ------------------------------------- |
| `id`                                           | `text (PK)`   | UUID                                  |
| `level`                                        | `text`        | `debug`/`info`/`warn`/`error`/`fatal` |
| `message`                                      | `text`        | Log message                           |
| `service`                                      | `text`        | Service name                          |
| `timestamp`                                    | `timestamptz` | Creation time                         |
| `metadata`                                     | `jsonb`       | Extra data                            |
| `error_name` / `error_message` / `error_stack` | `text`        | Error fields                          |
| `trace_id` / `span_id`                         | `text`        | From metadata                         |
| `tenant_id`                                    | `text`        | default `"default"`                   |
| `user_id` / `request_id`                       | `text`        | Associated ids                        |
| `duration_ms`                                  | `integer`     | Duration                              |

Receives `{ db: DatabaseUnit }` via injection.
