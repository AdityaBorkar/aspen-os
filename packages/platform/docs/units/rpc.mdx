The `RpcUnit` (`$name: "rpc"`) provides an RPC layer using [oRPC](https://orpc.uno) with input validation. It exposes a router and an HTTP handler.

## Configuration

```ts title="src/server/rpc/types.ts"
interface RpcConfig {
  prefix?: string; // default: "/api/rpc"
}
```

### Example

```ts
const rpcConfig: RpcConfig = {
  prefix: "/api/rpc",
};
```

## Public API

```ts title="src/server/rpc/index.ts"
class RpcUnit {
  readonly $name = "rpc";
  readonly router = router; // oRPC Router

  readonly server: {
    handle(
      request: Request,
      context: RpcContext,
    ): Promise<{ matched: boolean; response: Response | undefined }>;
    router: RpcRouter;
  };

  async $prepareInfra(): Promise<void>;
  async $cleanup(): Promise<void>;
}
```

## RPC Context

The RPC context provides `db` and `pubsub` to procedures at request time:

```ts title="src/server/rpc/types.ts"
interface RpcContext {
  db: PostgresJsDatabase;
  pubsub: PubSubUnit;
  tenantId?: string;
}
```

<Callout type="warn">
  The `RpcUnit` constructor accepts `{ auth, db, logs, pubsub }` as deps but does **not** use them at construction time. The `RpcContext` is passed at request time via `handle()`, not injected at construction.
</Callout>

## Handling Requests

```ts
const result = await platform.rpc.server.handle(request, {
  db: platform.db.db,
  pubsub: platform.pubsub,
});

if (result.matched) {
  return result.response;
}
// If not matched, fall through to other handlers
```

## Defining Procedures

Procedures are defined on the `base` handler (`os.$context<RpcContext>()`):

```ts title="src/server/rpc/procedures/echo.ts"
import { base } from "#/server/rpc/base";

export const echo = base.handler(async () => ({ echo: "input.message" }));
```

Input validation uses Standard Schema (Valibot in domain code) — pass a schema to the handler chain per oRPC's API.

## Router Structure

The router is a nested object of procedures:

```ts title="src/server/rpc/router.ts"
// router.ts
export const router = {
  echo: echoProcedure,
  health: {
    check: healthCheckProcedure,
  },
};
```

## Request Matching

The `handle()` method checks if the request URL starts with the configured `prefix`. If it matches, the oRPC handler processes the request. If not, it returns `{ matched: false, response: undefined }` so the caller can fall through to other handlers.

## Base Handler

The `base` handler is created with the `RpcContext` type:

```ts title="src/server/rpc/base.ts"
import { os } from "@orpc/server";
// base = os.$context<RpcContext>()
```

## Dependency

Receives `{ auth, db, logs, pubsub }` via constructor injection, though these are not used by the unit itself at construction time. The actual context (`RpcContext`) is provided at request time.
