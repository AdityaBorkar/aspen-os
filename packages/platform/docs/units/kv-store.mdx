The `KvStoreUnit` (`$name: "kvStore"`) provides a Redis-like API over a Postgres `UNLOGGED` table. Core unit — required in config.

## Configuration

```ts title="src/server/kv-store/types.ts"
interface KvStoreConfig {
  defaultTtl?: number; // default 3600 seconds
  keyPrefix?: string; // default ""
}
```

```ts
const kvConfig: KvStoreConfig = { defaultTtl: 1800, keyPrefix: "recruiter" };
```

## Features

### Basic get/set

```ts
await platform.kvStore.set("user:123:preferences", { theme: "dark" });
const prefs = await platform.kvStore.get("user:123:preferences"); // null if expired
await platform.kvStore.del("user:123:preferences");
const exists = await platform.kvStore.exists("user:123:preferences");
```

Strings stored as-is; others JSON-serialized.

### TTL

```ts
await platform.kvStore.set("otp:123", "123456", 300); // 5 min
await platform.kvStore.set("config:settings", config, 0); // never expires
```

<Callout type="info">
  Expired entries are lazily evicted on `get()` — deleted then `null` returned.
</Callout>

### Cache-aside

```ts
const dashboard = await platform.kvStore.getOrSet(
  "dashboard:org:123",
  async () => computeExpensiveDashboard("org-123"),
  3600,
);
```

### Counters

```ts
await platform.kvStore.increment("visits:page:home"); // → 1
await platform.kvStore.increment("visits:page:home", 5); // → 6
await platform.kvStore.decrement("credits:user:123");
```

### Pattern clear

```ts
await platform.kvStore.clear("user:123:*"); // * → %, ? → _ LIKE; cursor-scanned
await platform.kvStore.clear(); // scoped to tenant prefix
```

### Key prefixing

Keys are prefixed with `keyPrefix` + `tenantId` from context:

```ts
// config { keyPrefix: "recruiter" }, context { tenantId: "tenant_123" }
// set "user:123" → DB key "recruiter:tenant_123:user:123"
```

Without `keyPrefix`: `tenant_123:user:123`. `clear()` is tenant-scoped.

### Table

`kv_store` is `UNLOGGED` (no WAL — cache semantics, may lose data on crash).

| Column       | Type          | Description                |
| ------------ | ------------- | -------------------------- |
| `key`        | `text (PK)`   | Includes prefix + tenantId |
| `value`      | `text`        | JSON or raw string         |
| `expires_at` | `timestamptz` | nullable = no expiry       |
| `tenant_id`  | `text`        | default `"default"`        |
| `updated_at` | `timestamptz` | Last update                |

Receives `{ db: DatabaseUnit }` via injection.
