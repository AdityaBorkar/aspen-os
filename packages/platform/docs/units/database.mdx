The `DatabaseUnit` (`$name: "db"`) owns a control-plane `postgres-js` pool and Drizzle instance, plus lazily-created per-tenant pools.

## Configuration

```ts title="src/server/db/types.ts"
type DatabaseConfig = {
  database: string;
  host: string;
  password: string;
  port: number;
  ssl?: boolean;
  user: string;
  maxConnections?: number;
};
```

```ts
new DatabaseUnit(config.db);
```

`db` config is always the **control-plane** connection; per-tenant config derives from `IsolatedTenantDatabaseConfig` (`controlDbName`, `connection`, `tenantDbPrefix`, `tenantDbDefaults`).

## Features

### Stable wrapper

A `Proxy` that resolves per-request drizzle via `AsyncLocalStorage` — workflows keep `this.db = units.db.db` unchanged.

```ts
p.db.db; // stable wrapper — resolves per-request
p.db.controlPlaneDb; // direct control-plane instance
p.db.pool; // postgres-js Sql pool
```

### Schema push

Merged module schemas are pushed to the control-plane DB; `getSchemas()` returns platform core schemas (`user`, `session`, `account`, `verification`, `logs`, `file_metadata`, `kv_store`, `audit_log`, `workflow_runs`, `workflow_steps`).

```ts
await p.db.$prepareInfra(controlPlaneSchemas, tenantSchemas);
// $prepareInfra merges schemas from all ModuleInfra then pushes
```

No migrations — `pushSchema` only.

### Tenant pools

Lazily create and cache a per-tenant `postgres-js` pool.

```ts
await p.db.getTenantDb("tenant_123");
await p.db.pushSchemasToTenant("tenant_123", tenantSchemas);
await p.db.seedTenantDb(dbConfig, async (db) => {
  await db.insert(table).values(row);
});
```

### Tenant provisioning

Create the tenant DB and push schemas:

```ts
const result = await p.db.provisionTenant("tenant_123");
// → { tenancyMode: "isolated", database, host, ... }
```

### Request context

```ts
import { getContext } from "@aspen-os/platform/server";
await p.run("$global", async () => {
  const { db } = getContext(); // controlPlaneDb or tenant db
});
await p.run(tenantId, async () => {
  const { db, tenantId } = getContext();
});
```
