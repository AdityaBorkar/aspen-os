The `PubSubUnit` (`$name: "pubsub"`) provides typed publish/subscribe over [pg-boss](https://github.com/timgit/pg-boss), a Postgres job queue. One control-plane boss, started lazily on first use.

## Configuration

```ts title="src/server/pubsub/types.ts"
interface PubSubConfig {
  monitorIntervalSeconds?: number; // default 30
  schema?: string; // pg-boss schema (only when SSL)
}
```

```ts
const pubsubConfig: PubSubConfig = { monitorIntervalSeconds: 30 };
```

Connection pool is created by pg-boss from DB config — not reused from `DatabaseUnit`.

## Features

### Publishing

```ts
const jobId = await p.pubsub.publish("organization:created", { organization: { id: "org-1" } });
await p.pubsub.publish(
  "compliance:document_expiring",
  { documentId: "doc-1" },
  { retryLimit: 3, retryDelay: 60, retryBackoff: true, expireInMinutes: 60, priority: 1 },
);
await p.pubsub.publishBatch("notifications:send", [
  { data: { userId: "1", message: "Hello" } },
  { data: { userId: "2", message: "World" }, options: { priority: 2 } },
]);
```

<Callout type="warn">
  Publishing to a topic with no `subscribe()` is **silently dropped** (`send()` matches no queue →
  `null`; `publish()` logs warning and returns `undefined`). Use `getUnsubscribedProducedTopics()`
  to surface these.
</Callout>

### Subscribing

```ts
await p.pubsub.subscribe("organization:created", async (message) => {
  console.log(message.data, message.id, message.createdOn);
});
await p.pubsub.unsubscribe("organization:created");
```

Handlers' `getContext().db` resolves to the tenant DB in isolated mode when subscribed inside `p.run(tenantId, ...)`.

### Scheduling

```ts
await p.pubsub.schedule({ topic: "compliance:daily-expiry-scan", cron: "0 8 * * *" });
await p.pubsub.schedule({
  topic: "compliance:weekly-summary",
  cron: "0 9 * * 1",
  data: {},
  options: { tz: "Asia/Kolkata" },
});
const schedules = await p.pubsub.getSchedules();
await p.pubsub.unschedule("compliance:weekly-summary");
```

### Queue management

```ts
const size = await p.pubsub.getQueueSize("compliance:document_expiring"); // works on unregistered topics
await p.pubsub.purgeQueue("notifications:send");
```

`getQueueSize` is the connectivity probe used by `rpc health check`.

### Options & Message shape

```ts title="src/server/pubsub/types.ts"
interface PublishOptions {
  expireInMinutes?: number;
  priority?: number;
  retryBackoff?: boolean;
  retryDelay?: number;
  retryLimit?: number;
  startAfter?: Date | string;
}
interface ScheduleOptions extends PublishOptions {
  tz?: string;
}
interface Message<T> {
  id: string;
  name: string;
  data: T;
  createdOn: Date;
  completedOn?: Date;
}
type MessageHandler<T> = (message: Message<T>) => void | Promise<void>;
```

### Wiring

Receives `{ audit, db, log }` via injection, wired to `auth` via `pubsub.setAuth(auth)` in `createCore()`. `$prepareInfra()` is a no-op; `$cleanup()` stops the boss. Modules register in `$prepareRuntime()` and unregister in `$cleanup()`.
