The `StorageUnit` (`$name: "storage"`) provides file operations via an S3 adapter, enriched with Postgres `file_metadata` tracking via `FileMetadataService`.

## Configuration

```ts title="src/server/storage/types.ts"
interface StorageConfig {
  bucket: string;
  prefix?: string;
  provider: StorageProvider;
}
interface StorageProvider {
  type: "s3";
  endpoint: string;
  region: string;
  credentials: { accessKeyId: string; secretAccessKey: string };
  forcePathStyle: boolean;
}
```

```ts
const storageConfig: StorageConfig = {
  bucket: "recruiter",
  prefix: "uploads",
  provider: {
    type: "s3",
    endpoint: "http://localhost:8333",
    region: "us-east-1",
    credentials: { accessKeyId: "...", secretAccessKey: "..." },
    forcePathStyle: true,
  },
};
```

## Features

### Upload & download

```ts
const file = await platform.storage.upload({
  key: "documents/report.pdf",
  body: buffer,
  contentType: "application/pdf",
  metadata: { uploadedBy: userId },
});
// file = { key, etag, size, contentType, lastModified, metadata }
const buffer = await platform.storage.get("documents/report.pdf");
const metadata = await platform.storage.getMetadata("documents/report.pdf");
```

```ts title="src/server/storage/types.ts"
interface FileUploadInput {
  key: string;
  body: Buffer | ReadableStream | string;
  contentType?: string;
  cacheControl?: string;
  metadata?: Record<string, string>;
}
interface FileObject {
  key: string;
  etag: string;
  size: number;
  contentType?: string;
  lastModified: Date;
  metadata?: Record<string, string>;
}
```

### Signed URLs

```ts
const downloadUrl = await platform.storage.getSignedGetUrl("documents/report.pdf", {
  expiresIn: 3600,
  responseContentDisposition: 'attachment; filename="report.pdf"',
});
const uploadUrl = await platform.storage.getSignedPutUrl("uploads/user-avatar.jpg", {
  expiresIn: 1800,
});
```

### Archive / Copy / Move

```ts
await platform.storage.archive("documents/report.pdf"); // → archive/<key>
await platform.storage.archive("documents/report.pdf", "archive/2024/report.pdf");
await platform.storage.copy("source.pdf", "backup/source.pdf");
await platform.storage.move("temp/upload.pdf", "documents/final.pdf");
```

### Listing

```ts
const { files, nextContinuationToken } = await platform.storage.list("documents/", { maxKeys: 50 });
if (nextContinuationToken) {
  await platform.storage.list("documents/", {
    continuationToken: nextContinuationToken,
    maxKeys: 50,
  });
}
```

### Metadata table

All operations update `file_metadata`:

| Column                      | Type            | Description         |
| --------------------------- | --------------- | ------------------- |
| `id`                        | `text (PK)`     | UUID                |
| `key`                       | `text (unique)` | S3 key              |
| `bucket`                    | `text`          | Bucket              |
| `content_type`              | `text`          | MIME                |
| `size`                      | `bigint`        | Bytes               |
| `etag`                      | `text`          | S3 ETag             |
| `metadata`                  | `jsonb`         | Custom metadata     |
| `archived`                  | `boolean`       | Archived flag       |
| `archived_key`              | `text`          | Archive location    |
| `tenant_id`                 | `text`          | default `"default"` |
| `created_at` / `updated_at` | `timestamptz`   | Timestamps          |

### Key prefixing

```ts
// config { prefix: "uploads" }, context { tenantId: "tenant_123" }
// upload "documents/report.pdf" → S3 key "uploads/tenant_123/documents/report.pdf"
```

Receives `{ db: DatabaseUnit }` via injection.
