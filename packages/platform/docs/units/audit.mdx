The `AuditUnit` (`$name: "audit"`) records an append-only trail in `audit_log`. Always present — no config, only `{ db }` injection.

## Features

### Writing

```ts
import { getContext } from "@aspen-os/platform/server";
await p.run("$global", async () => {
  const { audit } = getContext();
  await audit.write({
    action: "organization.updated",
    crudAction: "update",
    entityId: "org-1",
    entityType: "organization",
    previousState,
    newState,
    changes: audit.diff(previousState, newState),
  });
});
```

### Atomic transaction

Write the entry in the same DB transaction as the operation:

```ts
await audit.withTransaction(
  (result) => ({
    action: "branch.created",
    crudAction: "create",
    entityId: result.id,
    entityType: "branch",
    newState: result,
  }),
  async () => db.insert(branches).values({ name }).returning(),
);
```

`diff(before, after)` computes `{ new, old }` per changed key.

### Query & reconstruct

```ts
const entries = await audit.query({ entityType: "organization", entityId: "org-1" });
const count = await audit.count({ action: "organization.updated" });
const current = await audit.reconstructState("organization", "org-1"); // replay logs
```

### Entry shape

```ts title="src/server/audit/types.ts"
type CrudAction = "create" | "update" | "delete";
interface AuditEntry {
  action: string;
  actorId?: string;
  changes?: Record<string, JsonValue>;
  crudAction?: CrudAction;
  entityId: string;
  entityType: string;
  idempotencyKey?: string;
  metadata?: Record<string, JsonValue>;
  newState?: Record<string, JsonValue> | null;
  previousState?: Record<string, JsonValue> | null;
  requestId?: string;
  traceId?: string;
  workflowRunId?: string;
}
```

### Table

| Column                                        | Type          | Description                                       |
| --------------------------------------------- | ------------- | ------------------------------------------------- |
| `id`                                          | `text (PK)`   | `uuidv7`                                          |
| `seq`                                         | `bigserial`   | Monotonic ordering                                |
| `tenant_id`                                   | `text`        | `current_setting('app.tenant_id')` or `"default"` |
| `entity_type` / `entity_id`                   | `text`        | What changed                                      |
| `action` / `crud_action`                      | `text`        | Verb + `create`/`update`/`delete`                 |
| `actor_id`                                    | `text`        | Who                                               |
| `previous_state` / `new_state` / `changes`    | `jsonb`       | Snapshots + diff                                  |
| `metadata`                                    | `jsonb`       | Extra                                             |
| `idempotency_key`                             | `text`        | unique per `(tenant_id, idempotency_key)`         |
| `request_id` / `trace_id` / `workflow_run_id` | `text`        | Correlation                                       |
| `performed_at`                                | `timestamptz` | `now()`                                           |

Indexes on `(entity_type, entity_id, seq)`, `workflow_run`, `actor`, `action`, `performed_at`. `$prepareInfra` is a no-op — table owned by `DatabaseUnit`.
