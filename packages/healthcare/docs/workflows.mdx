Workflow groups via `p.healthcare`: `patients`, `practitioners`, `facilities`, `services`, `pricelists`, `appointments`, `encounters`, `admin`, `allopathy`, `dental`, `ayush`, `rehab`, `psych`, `residents`, `pharmacy`, `diagnostics`, `billing`, `nursing`, `records`, `operations`.

Staff, roster, attendance, leave, and payroll live in `@aspen-os/hr-core`, `@aspen-os/hr-attendance`, and `@aspen-os/hr-leave` (`p.hrCore.payroll.export` for the monthly payroll export).

Create takes Valibot `{ input }` with `branchId` (defaults `"main"`); reads take filter objects. Every mutation writes an audit entry and publishes a `healthcare.*` event; reads publish nothing.

## Features

### Patients

Access: `p.healthcare.patients`

Registration with phone/ABHA dedupe, family links, allergies, flags, consents, recalls, and two-party merge. Actions: `register`, `dedupeCheck`, `get`, `list`, `timeline`, `linkFamily`, `setFlag`, `addAllergy`, `archiveConsent`, `logCommunication`, `shareSlip`, `enrolRecall`, `requestMerge`, `approveMerge`.

```ts
const patient = await p.healthcare.patients.register({
  input: { branchId: "main", fullName: "Asha Rao", gender: "female", phone: "9820011223" },
});
await p.healthcare.patients.dedupeCheck({ input: { branchId: "main", phone: "9820011223" } });
await p.healthcare.patients.requestMerge({
  input: {
    branchId: "main",
    duplicateId: dup.id,
    primaryId: patient.id,
    reason: "double registration",
  },
});
```

### Practitioners

Access: `p.healthcare.practitioners`

Doctor masters with registrations, education, postings, weekly schedules, fee versions, and leave blocks. `conflict` reports leave and booked-appointment overlap; `nextFreeSlot` scans schedules minus booked slots over 14 days. Actions: `create`, `get`, `list`, `update`, `deactivate`, `addRegistration`, `addEducation`, `addPosting`, `setSchedule`, `setFee`, `blockLeave`, `conflict`, `nextFreeSlot`.

```ts
const doc = await p.healthcare.practitioners.create({
  input: {
    branchId: "main",
    name: "Dr. Iyer",
    overallYrs: 12,
    specialistYrs: 6,
    specialty: "cardiology",
  },
});
await p.healthcare.practitioners.setSchedule({
  input: {
    branchId: "main",
    bufferMin: 0,
    end: "13:00",
    facilityId: room.id,
    practitionerId: doc.id,
    slotMin: 15,
    start: "09:00",
    weekday: "mon",
  },
});
await p.healthcare.practitioners.nextFreeSlot({
  input: { branchId: "main", practitionerId: doc.id },
});
```

### Facilities

Access: `p.healthcare.facilities`

Rooms, chairs, and equipment with weekly schedules, blocks, single-occupancy occupy/release, and sterilization logs. Actions: `create`, `get`, `list`, `update`, `setSchedule`, `addBlock`, `overlap`, `occupy`, `release`, `logSterilization`, `statusBoard`.

```ts
const room = await p.healthcare.facilities.create({
  input: { branchId: "main", category: "consultation", code: "CONS-01", name: "Consultation 1" },
});
await p.healthcare.facilities.occupy({
  input: { branchId: "main", facilityId: room.id, note: "minor procedure" },
});
await p.healthcare.facilities.release({ input: { branchId: "main", facilityId: room.id } });
```

### Services

Access: `p.healthcare.services`

Billable services with versioned prices, discount rules, facility maps, and redeemable packages. Actions: `create`, `get`, `list`, `update`, `publish`, `retire`, `mapFacilities`, `setPrice`, `addDiscountRule`, `definePackage`, `redeem`.

```ts
const svc = await p.healthcare.services.create({
  input: { branchId: "main", code: "CONS-GEN", name: "General consultation" },
});
await p.healthcare.services.setPrice({
  input: { amount: 500, branchId: "main", serviceId: svc.id },
});
await p.healthcare.services.publish({ input: { branchId: "main", serviceId: svc.id } });
```

### Pricelists

Versioned pricelists with publish/retire lifecycle, bulk revision preview/apply, and price resolution with `DEFAULT` fallback.

```ts
const list = await p.healthcare.pricelists.create({
  input: { branchId: "main", code: "INS-A", name: "Insurer A" },
});
await p.healthcare.pricelists.publish({ input: { id: list.id } });
await p.healthcare.pricelists.resolvePrice({
  input: { branchId: "main", serviceId: svc.id, pricelistId: list.id },
});
```

`DEFAULT` is reserved for the seeded fallback pricelist; only published pricelists resolve prices.

### Appointments

Access: `p.healthcare.appointments`

Slot computation (schedules minus leaves, facility blocks, and booked slots), booking with clash guards, FIFO queue tokens, video sessions, consents, recalls, and certificates. Actions: `computeSlots`, `book`, `get`, `list`, `reschedule`, `cancel`, `checkin`, `queueBoard`, `walkinToken`, `callNext`, `bookVideo`, `captureConsent`, `issueRecall`, `issueCertificate`.

```ts
const slots = await p.healthcare.appointments.computeSlots({
  input: { branchId: "main", date: "2026-09-14", facilityId: room.id, practitionerId: doc.id },
});
const appt = await p.healthcare.appointments.book({
  input: {
    branchId: "main",
    patientId: patient.id,
    practitionerId: doc.id,
    slotStart: slots[0].slotStart,
  },
});
await p.healthcare.appointments.checkin({ input: { id: appt.id } });
```

### Encounters

Access: `p.healthcare.encounters`

The clinical visit: immutable after `sign`. Diagnoses (dedupe-guarded), prescriptions with interaction ack gates, 180-day refills, orders, vitals, follow-ups, and post-sign addenda. Actions: `create`, `get`, `sign`, `addDiagnosis`, `prescribe`, `refill`, `placeOrder`, `recordVitals`, `setFollowUp`, `addendum`.

```ts
const enc = await p.healthcare.encounters.create({
  input: { branchId: "main", patientId: patient.id, specialty: "allopathy", visitType: "new" },
});
await p.healthcare.encounters.addDiagnosis({
  input: {
    branchId: "main",
    code: "J06.9",
    encounterId: enc.id,
    kind: "provisional",
    label: "URI",
  },
});
await p.healthcare.encounters.sign({ input: { branchId: "main", encounterId: enc.id } });
```

### Admin

Access: `p.healthcare.admin`

Singleton company profile, branch CRUD on the shared `healthcare_branch` table, master-version/template/recall-rule stores, and audit-log queries. Actions: `getCompany`, `saveCompany`, `listBranches`, `createBranch`, `getBranch`, `updateBranch`, `listMasterVersions`, `saveMasterVersion`, `listTemplates`, `saveTemplate`, `deleteTemplate`, `listRecallRules`, `saveRecallRule`, `deleteRecallRule`, `logs`.

```ts
await p.healthcare.admin.saveCompany({ input: { name: "City Clinic", slug: "city-clinic" } });
await p.healthcare.admin.createBranch({
  input: { address: "Linking Rd", name: "Bandra", subdomain: "bandra" },
});
await p.healthcare.admin.logs({
  input: { action: "created", entityType: "healthcare:patient", limit: 50 },
});
```

### Allopathy

Access: `p.healthcare.allopathy`

SOAP notes, exam findings, chronic-parameter logs, immunizations, triage entries, and statutory register entries. Every writer gates on an open, same-patient encounter. Actions: `saveSoap`, `saveExam`, `logChronic`, `recordImmunization`, `triageEntry`, `registerEntry`, `listSoap`.

```ts
await p.healthcare.allopathy.saveSoap({
  input: {
    assessment: "viral",
    branchId: "main",
    diagnoses: [{ code: "J06.9", label: "URI", system: "ICD11" }],
    encounterId: enc.id,
    objective: "throat congested",
    patientId: patient.id,
    plan: "rest",
    subjective: "fever 3d",
  },
});
await p.healthcare.allopathy.triageEntry({
  input: {
    branchId: "main",
    encounterId: enc.id,
    patientId: patient.id,
    priority: "routine",
    spo2: 98,
  },
});
```

Actions: `saveCaseSheet`, `repertorize`, `dualCode`, `bookNadi`, `scheduleTherapy`, `recordSitting`, `sellPackage`, `pauseExtendPackage`, `issueDiet`, `enrollYoga`, `createYogaBatch`.

```ts
const sheet = await p.healthcare.ayush.saveCaseSheet({
  input: {
    branchId: "main",
    complaints: "joint pain",
    dosha: "vata",
    encounterId: enc.id,
    nadi: "vataja",
    pathy: "ayurveda",
    patientId: patient.id,
    prakriti: "vata",
  },
});
await p.healthcare.ayush.dualCode({
  input: {
    branchId: "main",
    caseId: sheet.id,
    encounterId: enc.id,
```

```ts
  input: {

    branchId: "main",
```

```ts
const order = await p.healthcare.diagnostics.orderLabs({

    branchId: "main",
    encounterId: enc.id,
    patientId: patient.id,
    priority: "routine",
```

### Billing

Access: `p.healthcare.billing`

Invoices with source-traced lines, maker-checker discounts, multi-mode collection, package sell/redeem/expiry, forward-only pricelists, credit/debit notes, advances, dues aging, and GST export. Actions: `invoiceRaise`, `invoiceFinalize`, `interimTab`, `applyDiscount`, `collect`, `settle`, `packageSell`, `packageRedeem`, `packageExpireRun`, `repriceOnPayerSwitch`, `cndnIssue`, `settleAdvance`, `duesAging`, `gstExport`, `getInvoice`.

```ts
const inv = await p.healthcare.billing.invoiceRaise({
  input: {
    branchId: "main",
    encounterId: enc.id,
    lines: [{ price: 500, qty: 1, serviceId: svc.id, source: "consult" }],
    patientId: patient.id,
  },
});
await p.healthcare.billing.invoiceFinalize({ input: { branchId: "main", invoiceId: inv.id } });
await p.healthcare.billing.collect({
  input: { amount: 500, branchId: "main", invoiceId: inv.id, mode: "upi" },
});
```

### Operations

Access: `p.healthcare.operations`

Masters with version records, preset seeding, grant-gated explorer queries with CSV export, report definitions with computed runs, compliance evidence, and audit queries. Actions: `mastersUpsert`, `mastersGet`, `seedPresets`, `explorerQuery`, `explorerExportCsv`, `reportsDefine`, `reportsGet`, `reportsList`, `reportsRun`, `complianceEvidence`, `complianceList`, `explorerGrant`, `auditQuery`. Outbound delivery is owned by `comms` (see `shareWhatsapp`, `sendFamilySummary`).

```ts
await p.healthcare.operations.mastersUpsert({
  input: { branchId: "main", domain: "complaints", key: "fever", value: "Fever" },
});
await p.healthcare.operations.explorerQuery({
  input: { branchId: "main", collection: "healthcare_invoice", limit: 50 },
});
```
