The Healthcare module publishes domain events as plain string topics via `PubSub`. Every writer payload is a `HealthcareEntityEvent` (`{ id, branchId, at, actorId?, data? }`); reads publish nothing.

## Event Map

Moved topics live in their own modules now: `emr.*` (`@aspen-os/emr`), `diagnostics.*` (`@aspen-os/diagnostics`), `pharmacy.*` (`@aspen-os/pharmacy`), and `inpatient.*` (`@aspen-os/inpatient`, consumed by `tasks` and `comms`).
