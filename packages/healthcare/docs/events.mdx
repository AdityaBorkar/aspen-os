The Healthcare module publishes domain events as plain string topics via `PubSub`. Every writer payload is a `HealthcareEntityEvent` (`{ id, branchId, at, actorId?, data? }`); reads publish nothing.

## Event Map

### Patient

| Event                        | Payload                 | Trigger                                                                                                                 |
| ---------------------------- | ----------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `healthcare.patient_created` | `HealthcareEntityEvent` | `patients.register`                                                                                                     |
| `healthcare.patient_updated` | `HealthcareEntityEvent` | `linkFamily`, `setFlag`, `addAllergy`, `archiveConsent`, `logCommunication`, `shareSlip`, `enrolRecall`, `requestMerge` |
| `healthcare.patient_merged`  | `HealthcareEntityEvent` | `patients.approveMerge`                                                                                                 |
