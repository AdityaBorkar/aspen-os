The DMS module is the single document/file surface: one `file` entity combining the free-form filesystem (folders, paths) with the class-first records system (triage, classes, versions). Sharing uses grants and public links, with contact grantees referencing `masters` contacts, retention policies, legal holds, and full-text search.
