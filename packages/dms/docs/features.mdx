DMS is the single home for all your files — upload, organise, share, and find them, with version history and safe deletion built in.

## Files and folders

- **Upload files** — Save one file or many at once into a folder.
- **Organise with folders** — Create, rename, move, and browse folders.
- **Edit details** — Update a file's name, description, or extra details.
- **Copy or move** — Duplicate a file into another folder or relocate it.
- **Download** — Get the file itself or a short-lived download link.

## Filing uploads

- **Triage inbox** — See uploads that still need to be filed.
- **File an upload** — Assign it a document type and number so it becomes searchable and shareable.

## Document types

- **Define a document type** — Create templates such as Invoice with the details each file must carry.
- **Add required fields** — Decide which details are mandatory for a type.
- **Retire a type** — Archive document types you no longer use.

## Versions

- **Save a new version** — Keep every revision of a file.
- **Browse history** — See all past versions of a file.
- **Roll back** — Make an older version the current one.
- **Delete an old version** — Remove revisions you no longer need.

## Sharing

- **Share with people** — Give viewing or editing access to a person, group, or external contact.
- **See who has access** — Review everyone a file or folder is shared with.
- **Change or stop sharing** — Adjust what someone can do, or remove their access.
- **Public links** — Create a link anyone can open, with optional password, view limits, or expiry.

## Tags

- **Create tags** — Add colour-coded labels to organise files.
- **Tag files and folders** — Stick one or more tags on any item.
- **Find by tag** — Pull up everything carrying a tag.

## Search and history

- **Full search** — Search across file names, descriptions, and document details.
- **Quick search** — Get type-ahead results as you type.
- **Activity history** — See who uploaded, shared, edited, or deleted a file.

## Trash, retention, and holds

- **Trash and restore** — Deleted files and folders can be brought back.
- **Empty trash** — Permanently erase trashed items when you are sure.
- **Automatic clean-up** — Old trashed or expired files are cleared after their keep period.
- **Legal hold** — Lock a file against deletion for legal reasons, and release it when cleared.
