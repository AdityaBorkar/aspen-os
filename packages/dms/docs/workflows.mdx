Workflow groups via `p.dms`: `files`, `folders`, `classes`, `labels`, `shares`, `trash`, `triage`, `holds`, `settings`, `search`, `activity`, `versions`, `access`, `archive`, `paths`, `storage`.

Scoped workflows require `entityType` + `entityId` where polymorphic (`labels`, `shares`, `access`); create takes Valibot `{ input }`, update takes `{ id, patch }` (or `{ id, input }`). Every mutation writes an audit entry and publishes a `dms:*` event.

## Features

### Files

Access: `p.dms.files`

Filesystem upload lands `active`; triage upload stays `triaged` until `classify`.

```ts
const folder = await p.dms.folders.create({ input: { name: "Projects", ownerId } });
const file = await p.dms.files.upload({
  input: { name: "invoice.pdf", folderId: folder.id, body, contentType: "application/pdf", ownerId },
});
const staged = await p.dms.files.upload({
  input: { name: "scan.pdf", body, contentType: "application/pdf", ownerId }, // triaged
});
await p.dms.files.uploadBulk({ input: { inputs: [...] } });

await p.dms.files.get({ id });
await p.dms.files.getById({ id });
await p.dms.files.download({ id, options: { expiresIn } });
await p.dms.files.getDownloadLink({ id, options: { expiresIn } });

await p.dms.files.update({ id, input: { metadata: { project: "Atlas" } } });
await p.dms.files.rename({ id, input: { name: "invoice-2026.pdf" } });
await p.dms.files.move({ id, input: { newFolderId } });
await p.dms.files.copy({ id, destFolderId });
await p.dms.files.addMetadata({ id, input: { key: "project", value: "Atlas" } });
await p.dms.files.removeMetadata({ id, input: { key: "project" } });

await p.dms.files.delete({ id }); // → trashed
await p.dms.files.restore({ id, expiryDate });
await p.dms.files.purge({ id });
```

### Folders

Access: `p.dms.folders`

Materialized paths with cycle-safe, depth-bounded moves. `delete` soft-deletes to trash.

```ts
await p.dms.folders.create({ input: { name: "Projects", ownerId, parentId: null } });
await p.dms.folders.rename({ id, input: { name: "Projects 2026" } });
await p.dms.folders.move({ id, input: { newParentId } });
await p.dms.folders.update({ id, input: { color: "#3B82F6" } });
await p.dms.folders.delete({ id, force: false });
await p.dms.folders.restore({ id });
await p.dms.folders.get({ id }); // includes childCount + totalSize
await p.dms.folders.getById({ id });
await p.dms.folders.list({ id, opts: { search, sortBy, sortOrder } });
```

### Classes

Access: `p.dms.classes`

Class-first records system with file-naming schema applied as a metadata-only rename at classify time.

```ts
const cls = await p.dms.classes.create({ input: { name: "Invoice", createdBy: adminId } });
await p.dms.classes.addField({
  input: {
    classId: cls.id,
    name: "invoiceNumber",
    label: "Invoice Number",
    type: "text",
    isRequired: true,
  },
});
await p.dms.classes.list({ filters: { activeOnly: true } });
await p.dms.classes.get({ id: cls.id });
await p.dms.classes.update({ id: cls.id, patch: { retentionDays: 90 } });
await p.dms.classes.updateField({ id: fieldId, patch: { isRequired: false } });
await p.dms.classes.deactivateField({ id: fieldId });
await p.dms.classes.archive({ id: cls.id });
```

### Labels

Access: `p.dms.labels`

Labels are `master_label` rows (unified Masters taxonomy); DMS stores only the `dms_entity_label` join.

```ts
await p.dms.labels.create({ input: { name: "Important", color: "#EF4444", isGlobal: true } });
await p.dms.labels.update({ id, input: { name, color } });
await p.dms.labels.list({ opts: { includeGlobal: true, ownerId } });
await p.dms.labels.apply({ input: { labelId, entityId, entityType: "file", appliedBy } });
await p.dms.labels.remove({ entityId, entityType, labelId });
await p.dms.labels.listByLabel({ labelId });
await p.dms.labels.delete({ id });
```

### Shares

Access: `p.dms.shares`

Grants to `user` | `group` | `contact` plus public links. Folder grants inherit down the tree. `contact` holds a Masters contact id.

```ts
await p.dms.shares.create({
  input: {
    entityId,
    entityType: "file",
    granteeId,
    granteeType: "user",
    permission: "viewer",
    sharedBy,
  },
});
await p.dms.shares.update({ id, patch: { permission: "editor" } });
await p.dms.shares.remove({ id });
await p.dms.shares.get({ id });
await p.dms.shares.list({ entityId, entityType });
await p.dms.shares.listByGrantee({ granteeId, granteeType });
await p.dms.shares.resolveToken({ input: { token } });
await p.dms.shares.listSharedWithMe({ userId });

await p.dms.shares.createPublicLink({
  input: { entityId, entityType, permission: "view", createdBy },
});
await p.dms.shares.updatePublicLink({ id, input: { maxViews, expiresAt } });
await p.dms.shares.resolvePublicLink({ input: { token, password } });
await p.dms.shares.listPublicLinks({ entityId, entityType });
await p.dms.shares.getPublicLink({ id });
await p.dms.shares.revokePublicLink({ id });
```

Only `active` files can be shared. Removing a Masters contact revokes its grants (`masters:contact_removed` bridge).

### Trash

Access: `p.dms.trash`

Retention counts from `deletedAt`/`expiredAt` per class (`retentionDays`) falling back to `defaultRetentionDays`; folders use `trashRetentionDays`.

```ts
await p.dms.trash.list({ filters: {} });
await p.dms.trash.restore({ id, entityType: "file", expiryDate });
await p.dms.trash.purgeExpired({});
await p.dms.trash.deletePermanently({ id, entityType: "file" });
await p.dms.trash.empty({ opts: { ownerId } });
```

Permanent deletes reject legal-held files. Auto-purge skips held files.

### Triage

Access: `p.dms.triage`

Classification validates required fields and assigns `docNumber`.

```ts
await p.dms.triage.list({ filters: {} });
await p.dms.triage.detail({ id }); // missing required fields per candidate class
await p.dms.triage.classify({ id, input: { classId, fieldValues: { invoiceNumber: "INV-1" } } });
```

### Holds

Access: `p.dms.holds`

Admin-only legal holds; `release` nulls `releasedAt`.

```ts
await p.dms.holds.place({ fileId, placedBy, reason: "Litigation hold" });
await p.dms.holds.release({ holdId, releasedBy });
await p.dms.holds.list({ fileId });
```

### Settings

Access: `p.dms.settings`

Tenant key–value store mirroring `masters.settings`.

```ts
await p.dms.settings.get({ key: "logDownloads" });
await p.dms.settings.set({ key: "logDownloads", value: true });
```

### Search

Access: `p.dms.search`

Records + filesystem merged search over current-version `name`, description, metadata, and `fieldValues` respecting `include_in_search`.

```ts
await p.dms.search.search({ query: "INV", options: { scope: "mine" } });
await p.dms.search.quick({ input: { query: "INV" }, userId });
```

### Activity

Access: `p.dms.activity`

Projection over the platform `AuditUnit` (`dms:file`, `dms:folder`, `dms:class`, `dms:share`), ordered by `seq`.

```ts
await p.dms.activity.get({ entityId: fileId, entityType: "file" });
await p.dms.activity.getFile({ fileId });
await p.dms.activity.getClass({ classId });
```

### Versions

Access: `p.dms.versions`

`new` and `revert` create a new current version; `delete` cannot delete the current.

```ts
await p.dms.versions.new({ fileId, input: { body, name, contentType } });
await p.dms.versions.list({ fileId });
await p.dms.versions.getCurrent({ fileId });
await p.dms.versions.get({ fileId, version: 2 });
await p.dms.versions.revert({ fileId, version: 2 });
await p.dms.versions.delete({ fileId, version: 2 });
```

### Access

Access: `p.dms.access`

Folder inheritance up the chain; `logAccess` records public-link access.

```ts
await p.dms.access.checkPermission({ entityId, entityType, userId, required: "editor" });
await p.dms.access.getEffectivePermission({ entityId, entityType, userId });
await p.dms.access.isOwner({ entityId, entityType, userId });
await p.dms.access.logAccess({
  entityId,
  entityType,
  action: "public_link_accessed",
  publicLinkId,
});
```

### Archive

Access: `p.dms.archive`

Folder export as archive.

```ts
await p.dms.archive.createArchive({ folderId, options: { includeSubfolders: true } });
await p.dms.archive.processArchiveJob({ folderId, includeSubfolders: true });
```

### Paths

Access: `p.dms.paths`

Materialized-path helpers; `wouldCreateCycle` guards folder moves.

```ts
await p.dms.paths.resolvePath({ path: "/Projects/2026" });
await p.dms.paths.getBreadcrumbs({ folderId });
await p.dms.paths.checkNameUniqueness({ name, parentId });
await p.dms.paths.computeFilePath({ fileId });
await p.dms.paths.getSubtreeMaxDepth({ folderId });
```

### Storage

Access: `p.dms.storage`

StorageUnit bridge under version-bound keys.

```ts
await p.dms.storage.getSignedGetUrl({ key, expiresIn: 3600 });
await p.dms.storage.upload({ key, body, contentType });
await p.dms.storage.copy({ from: oldKey, to: newKey });
```
