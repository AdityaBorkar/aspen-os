The DMS module declares 14 tables, all in tenant schemas (no control-plane tables). Every table uses `text("id")` with `.primaryKey().$defaultFn(uuidv7)`. Timestamps use `TIMESTAMPTZ` (`withTimezone: true`).

## Enums

| Enum                         | Column                       | Values                                                                                                    |
| ---------------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------- |
| `dms_file_status`            | `dms_file.status`            | `triaged`, `active`, `expired`, `trashed`                                                                 |
| `dms_field_type`             | `dms_class_field.type`       | `text`, `number`, `date`, `select`, `multi-select`, `boolean`, `user`, `contact`, `url`, `email`, `phone` |
| `dms_grantee_type`           | `dms_share.grantee_type`     | `user`, `group`, `contact`                                                                                |
| `dms_share_permission`       | `dms_share.permission`       | `viewer`, `editor`, `owner`                                                                               |
| `dms_public_link_permission` | `dms_public_link.permission` | `view`, `edit`                                                                                            |

The polymorphic `entity_type` columns (`dms_entity_label`, `dms_share`, `dms_public_link`, `dms_access_log`) use the `dms_entity_type` enum (`file`, `folder`).

## Tables

### `dms_file`

The single file entity — a merge of the former `dms_document` (records) and `dms_file` (filesystem) tables. Has a GIN expression index over `to_tsvector('simple', name || description || metadata || field_values)` for full-text search.

| Column                      | Type          | Description                                                                                            |
| --------------------------- | ------------- | ------------------------------------------------------------------------------------------------------ |
| `id`                        | text (PK)     | Auto UUIDv7                                                                                            |
| `name`                      | text          | Current file name (may differ from the current version's original name if a naming schema was applied) |
| `version`                   | integer       | Current version number (starts at 1)                                                                   |
| `storage_key`               | text          | `dms/{tenant}/{id}/v{version}/{safeName}`                                                              |
| `content_type`              | text          | MIME type                                                                                              |
| `size`                      | bigint        | Bytes of current version                                                                               |
| `etag`                      | text          | S3 ETag for integrity                                                                                  |
| `folder_id`                 | text          | Containing folder; `null` for triage-staged files                                                      |
| `path`                      | text (unique) | Materialized path when in a folder (`/Projects/2026/invoice.pdf`); `null` for triage-staged files      |
| `description`               | text          | Optional free-text description                                                                         |
| `class_id`                  | text (FK)     | Class; `null` while triaged                                                                            |
| `doc_number`                | text (unique) | `DOC-000123`, assigned on classification; `null` for plain filesystem files                            |
| `field_values`              | jsonb         | Values for the assigned class fields (validated on classify)                                           |
| `status`                    | enum          | `triaged`, `active`, `expired`, `trashed`                                                              |
| `metadata`                  | jsonb         | Free-form key/value                                                                                    |
| `compression`               | jsonb         | Per-file compression override                                                                          |
| `batch_id`                  | text          | Groups bulk uploads                                                                                    |
| `owner_id`                  | text          | Owner                                                                                                  |
| `uploaded_by`               | text          | Who performed the upload                                                                               |
| `expiry_date`               | date          | Optional expiry; when passed, status → `expired`                                                       |
| `expired_at`                | timestamptz   | Expiry transition timestamp                                                                            |
| `deleted_at`                | timestamptz   | Trash transition timestamp                                                                             |
| `deleted_by`                | text          | Who soft-deleted                                                                                       |
| `created_at` / `updated_at` | timestamptz   | Record timestamps                                                                                      |

Indexes: `status`, `class_id`, `folder_id`, `owner_id`, `batch_id`, `expiry_date`, `path`, GIN `search_vector`.

### `dms_file_version`

| Column         | Type        | Description                                             |
| -------------- | ----------- | ------------------------------------------------------- |
| `id`           | text (PK)   | Auto UUIDv7                                             |
| `file_id`      | text (FK)   | Owning file                                             |
| `version`      | integer     | 1-based, unique per file                                |
| `storage_key`  | text        | S3 key for this revision                                |
| `name`         | text        | Original file name at the time this version was written |
| `content_type` | text        | MIME of this version                                    |
| `size`         | bigint      | Bytes of this version                                   |
| `etag`         | text        | S3 ETag of this version                                 |
| `compression`  | jsonb       | Compression applied to this version                     |
| `uploaded_by`  | text        | Who created the version                                 |
| `is_current`   | boolean     | Mirrors the file's current version (fast join)          |
| `created_at`   | timestamptz | Version creation timestamp                              |

Unique index on `(file_id, version)`. Indexed on `file_id`.

### `dms_folder`

| Column                      | Type                  | Description                                       |
| --------------------------- | --------------------- | ------------------------------------------------- |
| `id`                        | text (PK)             | Auto UUIDv7                                       |
| `name`                      | text                  | Folder name                                       |
| `path`                      | text (unique)         | Materialized hierarchical path (`/Projects/2026`) |
| `parent_id`                 | text                  | Parent folder; `null` = root                      |
| `owner_id`                  | text                  | Creator                                           |

Folders are containers, not files — they keep their own `is_trashed`. Indexed on `parent_id`, `owner_id`, `path`, `is_trashed`.

### `dms_class_field`

| Column                      | Type        | Description                                                                                               |
| --------------------------- | ----------- | --------------------------------------------------------------------------------------------------------- |
| `id`                        | text (PK)   | Auto UUIDv7                                                                                               |
| `class_id`                  | text (FK)   | Owning class                                                                                              |

### `dms_label` & `dms_entity_label`

`dms_label` defines color-coded labels (`name`, `color`, `is_global`, `owner_id`; global labels have `owner_id` null). `dms_entity_label` is a polymorphic join (`entity_id`, `entity_type` file/folder, `label_id`, `applied_by`, `applied_at`) with a unique constraint on `(entity_type, entity_id, label_id)`. A file or folder can carry multiple labels. (The former tag system was removed; labels are the single labeling mechanism.)

| --------------------------- | ----------- | ------------------------------------------------ |

| `name`                      | text        | View title                                       |

### `dms_share`

The unified sharing table — grants to `user`/`group`/`contact` over polymorphic `file`/`folder` entities. Merges the former `dms_share` and `dms_item_share`.

| Column         | Type        | Description                         |
| -------------- | ----------- | ----------------------------------- |
| `id`           | text (PK)   | Auto UUIDv7                         |
| `entity_type`  | enum        | `file` or `folder`                  |
| `entity_id`    | text        | Shared file or folder               |
| `grantee_type` | enum        | `user`, `group`, or `contact`       |
| `grantee_id`   | text        | Grantee ID                          |
| `permission`   | enum        | `viewer`, `editor`, or `owner`      |
| `share_token`  | text        | Access token for `contact` grantees |
| `message`      | text        | Optional note                       |
| `shared_by`    | text        | Who created                         |
| `expires_at`   | timestamptz | Optional expiry                     |
| `created_at`   | timestamptz | Share creation                      |

Unique on `(entity_type, entity_id, grantee_type, grantee_id)`. Indexed on `(entity_id, entity_type)` and `(grantee_id, grantee_type)`. Folder grants inherit down the folder tree.

### `dms_public_link`

| Column                      | Type          | Description                     |
| --------------------------- | ------------- | ------------------------------- |

Managed by the same `shares` group as grants. Indexed on `(entity_id, entity_type)`, `is_active`.

### `dms_legal_hold`

| ------------- | ----------- | ----------------------------- |
| `id`          | text (PK)   | Auto UUIDv7                   |

| `reason`      | text        | Mandatory justification       |

### `dms_access_log`

| Column                      | Type        | Description                  |
| --------------------------- | ----------- | ---------------------------- |
| `id`                        | text (PK)   | Auto UUIDv7                  |
| `entity_id` / `entity_type` | text / enum | Accessed entity              |
| `action`                    | text        | e.g. `public_link_accessed`  |
| `accessed_by`               | text        | User ID (null for anonymous) |

## Relationships

```text
dms_file ──N:1──→ dms_class (class assignment)
dms_file ──1:N──→ dms_file_version (version history)
dms_class ──1:N──→ dms_class_field (class schema)
dms_folder ──1:N──→ dms_folder (parent/child, self-referential)
dms_folder ──1:N──→ dms_file (folder contents)
dms_label ──N:M──→ dms_file / dms_folder (via dms_entity_label)
dms_file / dms_folder ──1:N──→ dms_share (grants, inherited up the folder chain)
dms_file / dms_folder ──1:N──→ dms_public_link (shareable links)
dms_file / dms_folder ──1:N──→ dms_access_log (access tracking)
dms_contact ──1:N──→ dms_share (contact grants)
dms_file ──1:N──→ dms_legal_hold (legal holds)
```
