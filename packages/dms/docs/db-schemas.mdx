The DMS module declares 20 tables, all in tenant schemas (no control-plane tables). Every table uses `text("id")` with `.primaryKey().$defaultFn(uuidv7)`. Timestamps use `TIMESTAMPTZ` (`withTimezone: true`).

## Tables

### `dms_document`

Central record. Every uploaded file becomes one row. Has a GIN expression index over `to_tsvector('simple', name || tags || metadata || field_values)` for full-text search.

| Column | Type | Description |
|---|---|---|
| `id` | text (PK) | Auto UUIDv7 |
| `doc_number` | text (unique) | Sequential `DOC-000123` |
| `name` | text | Current file name (may differ from the current version's original name if a naming schema was applied) |
| `version` | integer | Current version number (starts at 1) |
| `storage_key` | text | `dms/{tenant}/{id}/v{version}/{safeName}` |
| `content_type` | text | MIME type |
| `size` | bigint | Bytes of current version |
| `etag` | text | S3 ETag for integrity |
| `class_id` | text (FK) | Document class; `null` while triaged |
| `status` | enum | `triaged`, `active`, `expired`, `deleted` |
| `tags` | jsonb | `string[]` — denormalized tag names |
| `metadata` | jsonb | Free-form key/value |
| `field_values` | jsonb | Values for the assigned class fields (validated on classify) |
| `compression` | jsonb | Per-document compression override |
| `batch_id` | text | Groups bulk uploads |
| `owner_id` | text | Uploader |
| `uploaded_by` | text | Who performed the upload |
| `expiry_date` | date | Optional expiry; when passed, status → `expired` |
| `expired_at` / `deleted_at` | timestamptz | State transition timestamps |
| `deleted_by` | text | Who soft-deleted |
| `created_at` / `updated_at` | timestamptz | Record timestamps |

Indexes: `status`, `class_id`, `batch_id`, `owner_id`, `uploaded_by`, `expiry_date`, GIN `search_vector`.

### `dms_tag` & `dms_document_tag`

Simple many-to-many tag system. `dms_tag.name` is unique. `dms_document_tag` has a unique constraint on `(document_id, tag_id)`. The `dms_document.tags` JSONB column is a denormalized copy for fast search.

## Relationships

```text
dms_document ──N:1──→ dms_document_class (class assignment)
dms_document ──1:N──→ dms_document_version (version history)
dms_document_class ──1:N──→ dms_class_field (class schema)
dms_document ──N:M──→ dms_tag (via dms_document_tag)
dms_document ──1:N──→ dms_share (grants)
dms_contact ──1:N──→ dms_share (contact grants)
dms_document ──1:N──→ dms_legal_hold (legal holds)
dms_view ──1:N──→ dms_pin (sidebar pins by owner)

dms_folder ──1:N──→ dms_folder (parent/child, self-referential)
dms_folder ──1:N──→ dms_file (folder contents)
dms_file ──1:N──→ dms_file_version (version history)
dms_label ──N:M──→ dms_file / dms_folder (via dms_item_label)
dms_file / dms_folder ──1:N──→ dms_item_share (grants, inherited up the folder chain)
dms_file / dms_folder ──1:N──→ dms_public_link (shareable links)
dms_file / dms_folder ──1:N──→ dms_access_log (access tracking)
```

### `dms_label` & `dms_item_label`

`dms_label` defines color-coded labels (`name`, `color`, `is_global`, `owner_id`; global labels have `owner_id` null). `dms_item_label` is a polymorphic join (`item_id`, `item_type` file/folder, `label_id`, `applied_by`, `applied_at`) with a unique constraint on `(item_id, item_type, label_id)`.

### `dms_item_share`

| Column | Type | Description |
|---|---|---|
| `id` | text (PK) | Auto UUIDv7 |
| `item_id` / `item_type` | text / enum | Shared file or folder |
| `grantee_type` | enum | `user` or `group` |
| `grantee_id` | text | Grantee ID |
