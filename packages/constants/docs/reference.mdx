Shared `as const` enum objects, derived union types, and ISO 3166-1 country code utilities consumed by every domain module.

<Callout type="info">
  Build exception: `package.json` defines no `build` field, so `scripts/build.ts` leaves `exports`
  at `./src/index.ts` and only emits declarations into `.output`. Consumers always resolve
  TypeScript source, never bundled JS.
</Callout>

## Public API

Every domain module follows one pattern — an `as const` object plus a derived union:

```ts title="packages/constants/src/organization.ts"
export const ORGANIZATION_STATUS = {
  ACTIVE: "active",
  ARCHIVED: "archived",
  SUSPENDED: "suspended",
} as const;

export type OrganizationStatus = (typeof ORGANIZATION_STATUS)[keyof typeof ORGANIZATION_STATUS];
```

```ts title="packages/constants/src/country-codes.ts"
export const COUNTRY_CODES = [...] as const; // 249 ISO 3166-1 alpha-2 codes

export type CountryCode = (typeof COUNTRY_CODES)[number];

export function isValidCountryCode(code: string): code is CountryCode;
export function parseCountryCode(input: string): CountryCode | undefined;
```

```ts
import { ORGANIZATION_STATUS, type OrganizationStatus } from "@aspen-os/constants";

const status: OrganizationStatus = ORGANIZATION_STATUS.ACTIVE; // "active"
```

### Country codes (`src/country-codes.ts`)

```ts
import {
  COUNTRY_CODES,
  type CountryCode,
  isValidCountryCode,
  parseCountryCode,
} from "@aspen-os/constants";

const code: CountryCode = "US";

function setCountry(input: string): CountryCode {
  const parsed = parseCountryCode(input);
  if (parsed === undefined) {
    throw new Error(`Unknown country code: ${input}`);
  }
  return parsed; // normalized to uppercase CountryCode
}

function isCountry(input: string): input is CountryCode {
  return isValidCountryCode(input); // strict: only uppercase codes narrow
}

COUNTRY_CODES; // readonly ["AD", "AE", ..., "ZW"] — 249 ISO 3166-1 alpha-2 codes
```

<Callout type="warn">
  `parseCountryCode` uppercases before matching, but `isValidCountryCode` does not — lowercase input
  never narrows. Normalize first when the input is untrusted.
</Callout>
