The Compliance module defines 3 tables and 7 enums using Drizzle ORM. Audit trails are written to the platform's `audit_log` table via `AuditUnit`, not a module table.

## Enums

| Enum                   | Used in                                                                  | Values                                                                                                                                                                                                                                                                           |
| ---------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `category`             | `document.category`, `obligation.category`, `verification_rule.category` | `tax`, `license`, `certificate`, `permit`, `insurance`, `regulatory`, `legal`, `hr`, `safety`, `environmental`, `audit`, `data_privacy`, `financial`, `property`, `vehicle`, `other`                                                                                             |
| `verification_status`  | `document.verification_status`                                           | `draft`, `submitted`, `under_review`, `verified`, `rejected`, `expired`, `overdue`, `renewed`, `archived`                                                                                                                                                                        |
| `renewal_frequency`    | `document.renewal_frequency`                                             | `monthly`, `quarterly`, `semi_annual`, `annual`, `biennial`, `triennial`, `one_time`                                                                                                                                                                                             |

## Relationships

```text
obligation ──1:N (soft FK obligation_id)──→ document
document   ──self-ref (soft FK renewed_from)──→ document
organization branch   ──1:N (soft FK branch)──→ document
organization connection ──1:N (soft FK connection)──→ document
external entity {sourceModule, sourceEntityType, sourceEntityId} ←── document / obligation
```
