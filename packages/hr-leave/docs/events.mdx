The hr-leave module defines domain events for leave in one group. Events are type-level contracts published as plain string topics via `PubSubUnit`.

## Leave

| Event                         | Payload                                                                       | Trigger                         |
| ----------------------------- | ----------------------------------------------------------------------------- | ------------------------------- |
| `leave:application_submitted` | `{ application: { id, employeeId, leaveType, fromDate, toDate, totalDays } }` | `leave.createLeaveApplication`  |
| `leave:application_approved`  | `{ applicationId, approvedBy }`                                               | `leave.approveLeaveApplication` |
| `leave:application_rejected`  | `{ applicationId, rejectedBy }`                                               | `leave.rejectLeaveApplication`  |
| `leave:application_cancelled` | `{ applicationId }`                                                           | `leave.cancelLeaveApplication`  |
| `leave:allocation_created`    | `{ allocation: { id, employeeId, leaveType, totalDays } }`                    | `leave.createLeaveAllocation`   |
| `leave:encashment_requested`  | `{ encashment: { id, employeeId, leaveType, encashableDays } }`               | `leave.createLeaveEncashment`   |
