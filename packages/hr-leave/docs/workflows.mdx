The hr-leave module exposes the `leave` and `config` workflow groups via `p.hrLeave`.

Create inputs are Valibot-validated `{ input: Create*Input }`, update is `{ id, patch: Update*Input }` where `undefined` leaves a column untouched. Every command audit-logs and, where listed, publishes a domain event.

## Features

### Leave

Access: `p.hrLeave.leave`

Leave types, periods, policies, allocations, applications, encashment, compensatory leave, block lists, adjustments, and the append-only ledger.

```ts title="leave — types, periods, policies"
await p.hrLeave.leave.types.create({
  input: { name: "Sick Leave", maxDaysAllowed: 12, isCarryForward: true, maxCarryForwardDays: 5 },
});
await p.hrLeave.leave.types.update({ id, patch: { maxDaysAllowed: 15 } });
await p.hrLeave.leave.types.get({ id });
await p.hrLeave.leave.types.list({});
await p.hrLeave.leave.types.delete({ id }); // soft isActive=false

await p.hrLeave.leave.periods.create({
  input: { name: "FY 2026-27", startDate: "2026-04-01", endDate: "2027-03-31" },
});
await p.hrLeave.leave.periods.list({});

await p.hrLeave.leave.policies.create({ input: { name: "Standard Policy" } });
await p.hrLeave.leave.policyDetails.create({
  input: { leavePolicyId: "pol-1", leaveType: "lt-sick", maxDays: 12, carryForwardDays: 5 },
});
await p.hrLeave.leave.policyDetails.list({ leavePolicyId: "pol-1" });
await p.hrLeave.leave.policyDetails.delete({ id });

await p.hrLeave.leave.policyAssignments.create({
  input: {
    employeeId: "EMP-001",
    leavePolicy: "pol-1",
    leavePeriod: "per-2026",
    effectiveFrom: "2026-04-01",
  },
});
await p.hrLeave.leave.policyAssignments.list({ filters: { employeeId: "EMP-001" } });
```

```ts title="leave — allocations and applications"
await p.hrLeave.leave.allocations.create({
  input: { employeeId: "EMP-001", leaveType: "lt-sick", leavePeriod: "per-2026", totalDays: "12" },
});
await p.hrLeave.leave.allocations.update({ id, patch: { totalDays: "15" } });
await p.hrLeave.leave.allocations.get({ id });
await p.hrLeave.leave.allocations.list({ filters: { employeeId: "EMP-001" } });
await p.hrLeave.leave.balance.get({ employeeId: "EMP-001", leavePeriod: "per-2026" });

await p.hrLeave.leave.applications.create({
  input: {
    employeeId: "EMP-001",
    leaveType: "lt-sick",
    fromDate: "2026-09-10",
    toDate: "2026-09-11",
    totalDays: "2",
    reason: "Fever",
  },
});
await p.hrLeave.leave.applications.approve({ id, approvedBy: "mgr-1" }); // bumps usedDays + ledger
await p.hrLeave.leave.applications.reject({
  id,
  rejectedBy: "mgr-1",
  rejectionReason: "Insufficient balance",
});
await p.hrLeave.leave.applications.cancel({ id }); // reverses usedDays + ledger
await p.hrLeave.leave.applications.list({ filters: { employeeId: "EMP-001" } });
```

`applications.create` checks block lists and balance (skipped when `isLeaveWithoutPay`); `applications.cancel` floors `usedDays` at 0.

```ts title="leave — encashment, compensatory, block lists"
await p.hrLeave.leave.encashments.create({
  input: {
    employeeId: "EMP-001",
    leaveType: "lt-earn",
    leavePeriod: "per-2026",
    encashableDays: "5",
    encashedDays: "5",
  },
});
await p.hrLeave.leave.encashments.approve({ id, approvedBy: "mgr-1" });
await p.hrLeave.leave.encashments.reject({
  id,
  rejectedBy: "mgr-1",
  rejectionReason: "Not eligible",
});
await p.hrLeave.leave.encashments.markPaid({ id });
await p.hrLeave.leave.encashments.list({ filters: { employeeId: "EMP-001" } });

await p.hrLeave.leave.compensatoryLeaves.create({
  input: {
    employeeId: "EMP-001",
    leaveType: "lt-comp",
    workDate: "2026-09-06",
    numberOfDays: "1",
    reason: "Weekend support",
  },
});
await p.hrLeave.leave.compensatoryLeaves.approve({ id, approvedBy: "mgr-1" }); // creates allocation + ledger
await p.hrLeave.leave.compensatoryLeaves.list({ filters: { employeeId: "EMP-001" } });

await p.hrLeave.leave.blockLists.create({
  input: {
    name: "Year-end freeze",
    scope: "company",
    company: "ACME",
    fromDate: "2026-12-25",
    toDate: "2027-01-01",
  },
});
await p.hrLeave.leave.blockLists.list({ filters: {} });
```

```ts title="leave — adjustments and ledger"
await p.hrLeave.leave.adjustments.create({
  input: {
    employeeId: "EMP-001",
    leaveType: "lt-sick",
    days: "2",

await p.hrLeave.leave.adjustments.list({ employeeId: "EMP-001" });

```

### Config

Access: `p.hrLeave.config`

Holiday lists and holidays (moved from hr-core).

```ts title="config — holiday lists and holidays"
await p.hrLeave.config.holidayLists.create({ input: { name: "India 2026", year: 2026 } });
await p.hrLeave.config.holidayLists.update({ id, patch: { description: "National holidays" } });
await p.hrLeave.config.holidayLists.get({ id });
await p.hrLeave.config.holidayLists.list({});
await p.hrLeave.config.holidayLists.delete({ id }); // soft isActive=false

await p.hrLeave.config.holidays.create({
  input: { holidayListId: "hl-1", name: "Republic Day", date: "2026-01-26", type: "public" },
});
await p.hrLeave.config.holidays.update({ id, patch: { date: "2026-01-27" } });
await p.hrLeave.config.holidays.get({ id });
await p.hrLeave.config.holidays.listByList({ holidayListId: "hl-1" });
await p.hrLeave.config.holidays.delete({ id });
```
