The hr-leave module exposes one workflow group via `p.hrLeave`: `leave`.

Create inputs are Valibot-validated `{ input: Create*Input }`, update is `{ id, patch: Update*Input }` where `undefined` leaves a column untouched. Every command audit-logs and, where listed, publishes a domain event.

## Features

### Leave

Access: `p.hrLeave.leave`

Leave types, periods, policies, allocations, applications, encashment, compensatory leave, block lists, adjustments, and the append-only ledger.

```ts title="leave — types, periods, policies"
await p.hrLeave.leave.createLeaveType({
  input: { name: "Sick Leave", maxDaysAllowed: 12, isCarryForward: true, maxCarryForwardDays: 5 },
});
await p.hrLeave.leave.updateLeaveType({ id, patch: { maxDaysAllowed: 15 } });
await p.hrLeave.leave.getLeaveTypeById({ id });
await p.hrLeave.leave.listLeaveTypes({});
await p.hrLeave.leave.deleteLeaveType({ id }); // soft isActive=false

await p.hrLeave.leave.createLeavePeriod({
  input: { name: "FY 2026-27", startDate: "2026-04-01", endDate: "2027-03-31" },
});
await p.hrLeave.leave.listLeavePeriods({});

await p.hrLeave.leave.createLeavePolicy({ input: { name: "Standard Policy" } });
await p.hrLeave.leave.createLeavePolicyDetail({
  input: { leavePolicyId: "pol-1", leaveType: "lt-sick", maxDays: 12, carryForwardDays: 5 },
});
await p.hrLeave.leave.listLeavePolicyDetails({ leavePolicyId: "pol-1" });
await p.hrLeave.leave.deleteLeavePolicyDetail({ id });

await p.hrLeave.leave.createLeavePolicyAssignment({
  input: {
    employeeId: "EMP-001",
    leavePolicy: "pol-1",
    leavePeriod: "per-2026",
    effectiveFrom: "2026-04-01",
  },
});
await p.hrLeave.leave.listLeavePolicyAssignments({ filters: { employeeId: "EMP-001" } });
```

```ts title="leave — allocations and applications"
await p.hrLeave.leave.createLeaveAllocation({
  input: { employeeId: "EMP-001", leaveType: "lt-sick", leavePeriod: "per-2026", totalDays: "12" },
});
await p.hrLeave.leave.updateLeaveAllocation({ id, patch: { totalDays: "15" } });
await p.hrLeave.leave.getLeaveAllocationById({ id });
await p.hrLeave.leave.listLeaveAllocations({ filters: { employeeId: "EMP-001" } });
await p.hrLeave.leave.getLeaveBalance({ employeeId: "EMP-001", leavePeriod: "per-2026" });

await p.hrLeave.leave.createLeaveApplication({
  input: {
    employeeId: "EMP-001",
    leaveType: "lt-sick",
    fromDate: "2026-09-10",
    toDate: "2026-09-11",
    totalDays: "2",
    reason: "Fever",
  },
});
await p.hrLeave.leave.approveLeaveApplication({ id, approvedBy: "mgr-1" }); // bumps usedDays + ledger
await p.hrLeave.leave.rejectLeaveApplication({
  id,
  rejectedBy: "mgr-1",
  rejectionReason: "Insufficient balance",
});
await p.hrLeave.leave.cancelLeaveApplication({ id }); // reverses usedDays + ledger
await p.hrLeave.leave.listLeaveApplications({ filters: { employeeId: "EMP-001" } });
```

`createLeaveApplication` checks block lists and balance (skipped when `isLeaveWithoutPay`); `cancelLeaveApplication` floors `usedDays` at 0.

```ts title="leave — encashment, compensatory, block lists"
await p.hrLeave.leave.createLeaveEncashment({
  input: {
    employeeId: "EMP-001",
    leaveType: "lt-earn",
    leavePeriod: "per-2026",
    encashableDays: "5",
    encashedDays: "5",
  },
});
await p.hrLeave.leave.approveLeaveEncashment({ id, approvedBy: "mgr-1" });
await p.hrLeave.leave.rejectLeaveEncashment({
  id,
  rejectedBy: "mgr-1",
  rejectionReason: "Not eligible",
});
await p.hrLeave.leave.markLeaveEncashmentPaid({ id });
await p.hrLeave.leave.listLeaveEncashments({ filters: { employeeId: "EMP-001" } });

await p.hrLeave.leave.createCompensatoryLeave({
  input: {
    employeeId: "EMP-001",
    leaveType: "lt-comp",
    workDate: "2026-09-06",
    numberOfDays: "1",
    reason: "Weekend support",
  },
});
await p.hrLeave.leave.approveCompensatoryLeave({ id, approvedBy: "mgr-1" }); // creates allocation + ledger
await p.hrLeave.leave.listCompensatoryLeaves({ filters: { employeeId: "EMP-001" } });

await p.hrLeave.leave.createLeaveBlockList({
  input: {
    name: "Year-end freeze",
    scope: "company",
    company: "ACME",
    fromDate: "2026-12-25",
    toDate: "2027-01-01",
  },
});
await p.hrLeave.leave.listLeaveBlockLists({ filters: {} });
```
