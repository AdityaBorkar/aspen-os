> The Inventory module is not built yet. The list below describes what a future Inventory module would cover — none of this is available today.

## Planned: catalogue

- **Item catalogue (planned)** — Keep one record per product or material with units and details.

## Planned: stock

- **Stock by store (planned)** — See how much of each item sits in each warehouse or store.
- **Low-stock alerts (planned)** — Get warned when stock runs below a threshold.

## Planned: movements

- **Stock in and out (planned)** — Record purchases, issues, and consumption.
- **Transfers (planned)** — Move stock between stores.
- **Stock counts (planned)** — Reconcile physical counts with system stock.
