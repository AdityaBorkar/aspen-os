Workflow groups via `p.tasks` — `projects`, `tasks`, `statuses`, `taskTypes`, `timeEntries`, `comments`, `links`, `collaboration`, and `automations` (access key `p.tasks`).

Scope varies by group — projects own tasks via `projectId`; statuses, types, and automation rules are project-scoped or global (`projectId` nullable); time entries, comments, and links are task-scoped. Create takes `{ input }` (Valibot), update takes `{ id, patch }`, and mutations write `task_activity_log` and publish `task:*` events.

## Features

### Projects

```ts
await p.tasks.projects.create({ input: { name: "Roadmap", key: "ROAD", leadId, description } });
await p.tasks.projects.get({ id });
await p.tasks.projects.list();
await p.tasks.projects.update({ id, patch: { name, description } });
await p.tasks.projects.archive({ id });
await p.tasks.projects.restore({ id });
await p.tasks.projects.delete({ id }); // blocked when tasks exist

await p.tasks.projects.addMember({ input: { projectId, userId, role: "member" } });
await p.tasks.projects.updateMember({ projectId, userId, patch: { role: "admin" } });
await p.tasks.projects.removeMember({ projectId, userId });
await p.tasks.projects.listMembers({ projectId });
```

`key` is 2–10 uppercase letters, unique. `leadId` auto-added as `admin`. `delete` throws if tasks exist.

### Tasks

```ts
await p.tasks.tasks.create({
  input: {
    projectId,
    title,
    statusId,
    typeId,
    reporterId,
    priority: "high",
    labels,
    dueDate,
    parentId,
  },
});
await p.tasks.tasks.get({ id });
await p.tasks.tasks.list({ filters: { projectId, statusId, assigneeId, search } });
await p.tasks.tasks.update({ id, patch: { title, statusId, priority } });
await p.tasks.tasks.bulkUpdate({ input: { ids, patch: { priority: "urgent" } } }); // no statusId/parentId
await p.tasks.tasks.delete({ id });
await p.tasks.tasks.archive({ id });
await p.tasks.tasks.restore({ id });

await p.tasks.tasks.getSubTasks({ parentId });
await p.tasks.tasks.getCompletionSummary({ parentId });
await p.tasks.tasks.assign({ input: { taskId, userId, assignedBy, isLead } });
await p.tasks.tasks.unassign({ taskId, userId });
await p.tasks.tasks.getAssignees({ taskId });
await p.tasks.tasks.getLoggedHours({ taskId });
```

`number` is `KEY-SEQ` from `task_project.task_counter`. Parent must be same project; depth ≤3; cycles rejected. `isLead` clears prior lead.

### Statuses

```ts
await p.tasks.statuses.create({
  input: { name: "In Progress", category: "started", projectId, isDefault, isResolved, color },
});
await p.tasks.statuses.get({ id });
await p.tasks.statuses.list({ projectId });
await p.tasks.statuses.getGlobal();
await p.tasks.statuses.update({ id, patch: { name, category } });
await p.tasks.statuses.delete({ id });

await p.tasks.statuses.createTransition({
  input: { projectId, fromStatusId, toStatusId, requiresComment },
});
await p.tasks.statuses.deleteTransition({ id });
await p.tasks.statuses.listTransitions({ projectId });
await p.tasks.statuses.validateTransition({ fromStatusId, toStatusId, projectId }); // true when open model or rule exists
```

`isDefault` clears prior default in scope. `fromStatusId !== toStatusId`.

### Task types

```ts
await p.tasks.taskTypes.createTaskType({
  input: { name: "Bug", color, icon, projectId, isDefault },
});
await p.tasks.taskTypes.updateTaskType({ id, patch: { name } });
await p.tasks.taskTypes.deleteTaskType({ id });
await p.tasks.taskTypes.listTaskTypes({ projectId });

await p.tasks.taskTypes.createLabel({ input: { name: "frontend", color, projectId } }); // label helper, not master_label
await p.tasks.taskTypes.updateLabel({ id, patch: { name } });
await p.tasks.taskTypes.deleteLabel({ id });
await p.tasks.taskTypes.listLabels({ projectId });
```

Types and labels are project-scoped or global (`projectId` null). `isDefault` clears prior default in scope.

### Time entries

```ts
await p.tasks.timeEntries.create({
  input: { taskId, userId, duration: 60, date, description, billable },
});
await p.tasks.timeEntries.get({ id });
await p.tasks.timeEntries.list({ taskId });
await p.tasks.timeEntries.update({ id, patch: { duration } });
await p.tasks.timeEntries.delete({ id });
await p.tasks.timeEntries.getTotalDuration({ taskId, billableOnly: true });
```

`date` defaults to today. Duration in minutes.

### Comments

```ts
await p.tasks.comments.create({ input: { taskId, userId, body, parentId } });
await p.tasks.comments.get({ id });
await p.tasks.comments.listByTask({ taskId });
await p.tasks.comments.listReplies({ parentId });
await p.tasks.comments.update({ id, patch: { body } }); // sets edited_at
await p.tasks.comments.delete({ id }); // soft: is_deleted true, body "[comment deleted]"
```

Threaded via `parentId`.

### Links

```ts
await p.tasks.links.create({ input: { sourceId, targetId, linkType: "blocks" } });
await p.tasks.links.delete({ sourceId, targetId });
await p.tasks.links.listByTask({ taskId }); // { incoming, outgoing }
await p.tasks.links.topologicalSort({ taskIds });
await p.tasks.links.getCriticalPath({ projectId }); // { duration, path } by estimated_hours
await p.tasks.links.getDependencyGraph({ taskIds }); // nodes with dependsOn
```

`sourceId !== targetId`; `blocks` creates inverse `blocked_by` and checks cycles via BFS. `topologicalSort` throws on cycle.

### Collaboration

```ts
await p.tasks.collaboration.addWatcher({ input: { taskId, userId } }); // idempotent
await p.tasks.collaboration.removeWatcher({ taskId, userId });
await p.tasks.collaboration.listWatchers({ taskId });

await p.tasks.collaboration.addAttachment({ input: { taskId, fileId, uploadedBy, commentId } });
await p.tasks.collaboration.deleteAttachment({ id });
await p.tasks.collaboration.listAttachments({ taskId });
await p.tasks.collaboration.listAttachmentsByComment({ commentId });

await p.tasks.collaboration.getActivityLog({ taskId, action });
```

`assign` auto-adds watcher.

### Automations

```ts
await p.tasks.automations.create({
  input: { name, projectId, trigger: "status_change", conditions, actions, isActive },
});
await p.tasks.automations.get({ id });
await p.tasks.automations.listByProject({ projectId });
await p.tasks.automations.getActiveRules({ projectId, trigger });
await p.tasks.automations.update({ id, patch: { name, isActive } });
await p.tasks.automations.delete({ id });
await p.tasks.automations.evaluateRules({ projectId, taskId, trigger, values }); // exact-match conditions
```

Triggers `status_change`, `assignment_change`, `due_date_passed`, `task_created`, `task_updated`. Unparseable conditions never match.
