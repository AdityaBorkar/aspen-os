Tasks organises work into projects and tasks — with priorities, deadlines, discussions, time tracking, and automatic rules.

## Projects

- **Start a project** — Create a project with a short code and a lead.
- **Browse projects** — See all projects and open any of them.
- **Edit a project** — Rename it or update its details.
- **Archive and restore** — Shelve a project without deleting it, and bring it back later.
- **Invite people** — Add members, change their roles, or remove them.

## Tasks

- **Create a task** — Add work to a project with title, priority, dates, and estimate.
- **Break work down** — Split a task into smaller sub-tasks and track their progress.
- **Edit a task** — Update its title, status, priority, dates, and more.
- **Update many at once** — Change several tasks together.
- **Assign people** — Put one or more people on a task, including a lead.
- **Archive, restore, or delete** — Shelve finished tasks, bring them back, or remove them permanently.
- **Find tasks** — Filter across projects by status, person, label, and more.

## Workflow states

- **Custom states** — Add states such as To Do, In Progress, or Done for each project.
- **Shared states** — Reuse global states across projects.
- **Allowed moves** — Define which state changes are permitted and check a move before making it.

## Time tracking

- **Log time** — Record how long you spent on a task, including whether it is billable.
- **Review time** — See all time on a task and the total hours.
- **Correct entries** — Fix or remove a time entry.

## Discussion and files

- **Comment** — Discuss a task or reply in a thread.
- **Attach files** — Add files to a task or to a specific comment.
- **Follow a task** — Watch a task for updates, or stop following it.
- **See history** — Browse everything that happened on a task.

## Dependencies

- **Link tasks** — Mark tasks as related, blocking, or duplicated.
- **See the map** — View a visual map of how tasks depend on each other.
- **Work in order** — Get tasks sorted in the order they must be done.
- **Spot the critical path** — Find the chain of tasks that drives the deadline.

## Automation

- **Automatic rules** — Set up rules such as "when status changes, reassign" per project.
- **Turn rules on or off** — Edit, pause, or delete rules.
- **Check rules manually** — See which rules apply right now.
