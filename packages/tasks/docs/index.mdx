The Tasks module provides project-scoped task management with subtasks, dependency graphs, time tracking, comments, and automation rules. Saved views live in `@aspen-os/masters` (`p.masters.filterViews`, `domain: "tasks:task"`).

> Task reminders live in `@aspen-os/calendar` (`targetType = task`), driven by `task:due_date_changed` and cancelled on `task:deleted` / terminal `task:status_changed`.
