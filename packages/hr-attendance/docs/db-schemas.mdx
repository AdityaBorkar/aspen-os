The HR module declares 54 tables: 14 control-plane tables (setup + access, shared across tenants) and 40 tenant tables (operational/transactional). Every table uses `id: uuidv7("id").primaryKey()`. Cross-row links are soft text FKs (no DB constraints). Enum columns reference the 29 `hr_*` pgEnums — see `enums.mdx` for values.

Schema is applied with Drizzle `pushSchema()` during platform preparation; there are no migration files.
