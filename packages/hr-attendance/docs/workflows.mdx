The hr-attendance module exposes three workflow groups via `p.hrAttendance`: `attendance`, `overtime`, and `shift`.

Create inputs are Valibot-validated `{ input: Create*Input }`, update is `{ id, patch: Update*Input }` where `undefined` leaves a column untouched. Every command audit-logs and, where listed, publishes a domain event.

## Features

### Attendance

Access: `p.hrAttendance.attendance`

Attendance records, raw check-ins, correction requests, and period summaries. `getSummary` aggregates by `month` string; duplicate attendance per employee per date and future dates are rejected.

```ts title="attendance — records and check-ins"
await p.hrAttendance.attendance.create({
  input: { employeeId: "EMP-001", date: "2026-09-08", status: "present", shift: "shift-day" },
});
await p.hrAttendance.attendance.update({ id, patch: { status: "half_day" } });
await p.hrAttendance.attendance.getById({ id });
await p.hrAttendance.attendance.list({ filters: { employeeId: "EMP-001" } });
await p.hrAttendance.attendance.getSummary({ employeeId: "EMP-001", month: "2026-09" });
await p.hrAttendance.attendance.deleteRecord({ id });

await p.hrAttendance.attendance.createCheckin({
  input: { employeeId: "EMP-001", logType: "in", time: "2026-09-08T04:00:00Z", shift: "shift-day" },
});
await p.hrAttendance.attendance.getCheckinById({ id });
await p.hrAttendance.attendance.listCheckins({ filters: { employeeId: "EMP-001" } });
await p.hrAttendance.attendance.deleteCheckin({ id });
```

```ts title="attendance — correction requests"
await p.hrAttendance.attendance.createAttendanceRequest({
  input: {
    employeeId: "EMP-001",
    fromDate: "2026-09-01",
    toDate: "2026-09-02",
    reason: "Missed punch",
  },
});
await p.hrAttendance.attendance.updateAttendanceRequest({
  id,
  patch: { reason: "Missed punch — approved shift" },
});
await p.hrAttendance.attendance.approveAttendanceRequest({ id, approvedBy: "mgr-1" });
await p.hrAttendance.attendance.rejectAttendanceRequest({
  id,
  rejectedBy: "mgr-1",
  rejectionReason: "Insufficient proof",
});
await p.hrAttendance.attendance.listAttendanceRequests({ filters: { status: "pending" } });
await p.hrAttendance.attendance.deleteAttendanceRequest({ id });
```

### Overtime

Access: `p.hrAttendance.overtime`

Overtime rate types and dated slips with approval, rejection, and summary aggregation.

```ts title="overtime — types and slips"
await p.hrAttendance.overtime.createOvertimeType({
  input: {
    name: "Standard OT",
    amountCalculation: "fixed",
    fixedHourlyRate: "500",
    standardMultiplier: "1.5",
  },
});
await p.hrAttendance.overtime.updateOvertimeType({ id, patch: { weekendMultiplier: "2" } });
await p.hrAttendance.overtime.getOvertimeTypeById({ id });
await p.hrAttendance.overtime.listOvertimeTypes({});
await p.hrAttendance.overtime.deleteOvertimeType({ id }); // soft delete isActive=false

await p.hrAttendance.overtime.createOvertimeSlip({
  input: {
    employeeId: "EMP-001",
    overtimeType: "ot-standard",
    fromDate: "2026-09-01",
    toDate: "2026-09-02",
    standardHours: "4",
    holidayHours: "0",
    weekendHours: "2",
    totalOvertimeHours: "6",
  },
});
await p.hrAttendance.overtime.approveOvertimeSlip({ id, approvedBy: "mgr-1" }); // computes amount when fixed
await p.hrAttendance.overtime.rejectOvertimeSlip({
  id,
  rejectedBy: "mgr-1",
  rejectionReason: "Exceeds cap",
});
await p.hrAttendance.overtime.getOvertimeSummary({
  employeeId: "EMP-001",
  fromDate: "2026-09-01",
  toDate: "2026-09-30",
});
await p.hrAttendance.overtime.listOvertimeSlips({ filters: { status: "pending" } });
```

`getOvertimeSummary` sums only `approved` slips in the date range; `createOvertimeSlip` validates the overtime type exists.

### Shift

Access: `p.hrAttendance.shift`

Shift types, geofenced locations, dated assignments, requests, and weekly schedules.

```ts title="shift — types and locations"
await p.hrAttendance.shift.createShiftType({
  input: { name: "Day", startTime: "09:00", endTime: "18:00", lateEntryGraceMinutes: 10 },
});
await p.hrAttendance.shift.updateShiftType({ id, patch: { enableAutoAttendance: true } });
await p.hrAttendance.shift.getShiftTypeById({ id });
await p.hrAttendance.shift.listShiftTypes({});
await p.hrAttendance.shift.deleteShiftType({ id }); // soft isActive=false

await p.hrAttendance.shift.createShiftLocation({
  input: { name: "HQ Gate", latitude: "19.076", longitude: "72.877", radius: 500 },
});
await p.hrAttendance.shift.updateShiftLocation({ id, patch: { radius: 300 } });
await p.hrAttendance.shift.listShiftLocations({});
```

```ts title="shift — assignments, requests, schedules"
await p.hrAttendance.shift.createShiftAssignment({
  input: {
    employeeId: "EMP-001",
    shiftType: "shift-day",
    startDate: "2026-09-01",
    status: "active",
  },
});
await p.hrAttendance.shift.updateShiftAssignment({ id, patch: { endDate: "2026-12-31" } });
await p.hrAttendance.shift.deactivateShiftAssignment({ id }); // status → inactive
await p.hrAttendance.shift.listShiftAssignments({ filters: { employeeId: "EMP-001" } });

await p.hrAttendance.shift.createShiftRequest({
  input: {
    employeeId: "EMP-001",
    shiftType: "shift-night",
    fromDate: "2026-09-15",
    reason: "Personal",
  },
});
await p.hrAttendance.shift.approveShiftRequest({ id, approvedBy: "mgr-1" }); // creates assignment, links back
await p.hrAttendance.shift.rejectShiftRequest({
  id,
  rejectedBy: "mgr-1",
  rejectionReason: "Staffing",
});
await p.hrAttendance.shift.listShiftRequests({ filters: { status: "pending" } });

await p.hrAttendance.shift.createShiftSchedule({
  input: {
    name: "Mon-Fri Day",
    shiftType: "shift-day",
    monday: true,
    tuesday: true,
    wednesday: true,
    thursday: true,
    friday: true,
  },
});
await p.hrAttendance.shift.createShiftScheduleAssignment({
  input: { employeeId: "EMP-001", shiftSchedule: "sched-1", startDate: "2026-09-01" },
});
await p.hrAttendance.shift.listShiftSchedules({});
await p.hrAttendance.shift.listShiftScheduleAssignments({ employeeId: "EMP-001" });
```

`createShiftAssignment` / `createShiftRequest` / `createShiftSchedule` / `createShiftScheduleAssignment` validate the referenced `shift_type`/`shift_schedule` exists.

Events emitted by these workflows: [Events](/docs/hr-attendance/events). Tables touched: [DB Schemas](/docs/hr-attendance/db-schemas).
